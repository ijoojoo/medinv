## 可以体验的业务

- 采购/批发商品明细支持CSV UTF-8模板导入（每单50行、256 KB）、SKU与包装核对、逐行错误预览、待修正清单下载；默认追加，确认后可替换，继续编辑前可撤销导入。导出可选择完整原值（可再次导入）或当前显示列，文件标注编辑草稿，保留文本编码及数字精度。XLSX/XLS请先另存为CSV UTF-8；不导入单据表头或自动新建商品。

- 采购与批发新建、改单采用独立全页工作区，支持多张草稿标签、服务端自动/手动草稿、刷新恢复和“我的草稿”续录。返回记录保留应用筛选和分页；编辑草稿允许未填完，正式保存沿用原校验与审核，草稿转单在同一事务内防止重复创建。Ctrl+S保存草稿，税率↑↓选择常用值。个人字段模板及商品明细CSV导入导出已接入。

- 采购与批发销售的新建、改单共用多行表格：商品名称 / 编码 / 别名及多关键词检索，Enter / Tab 连续录入，Alt + ↑↓ 同列换行，插行、删行与撤销删除，Ctrl + Enter 保存。支持从表格粘贴 SKU 编码、数量、含税单价、税率，校验预览后整体填入，每单最多50行；重复商品保留独立行，空白尾行不提交。列名称、显隐、拖动顺序、固定/比例宽度、回车停留和显示格式按企业、账号、采购/销售类型保存在服务器，新建和改单共用。默认跳过单位和税率；显示格式不改变原值，隐藏错误字段会临时展开定位。零售录入仍沿用原界面。

- “设置 → 企业设置 → 基础资料 → 商品字段与分类规则”：管理员维护十品类树、字段目录、品类规则、全局固定布局和发布版本。配置草稿预览与正式发布分离；产品身份、字段含义与历史保持稳定。商品建档、修订、导入和审核共用后端验证；一类器械关联备案人与备案证，二、三类关联注册人与注册证。

- 本站账号密码登录（同源 Keycloak 统一样式）、会话刷新 / 退出、企业切换、成员角色和主体权限管理。
- 业务提交遇到网络中断或返回不完整时，保留“待确认提交”；同标签页刷新或重新登录后可按原内容继续确认，避免重新制单或重复记收付款。超过24小时或记录损坏时需人工核对；销售员可从原未过账发货单取消并释放预占。
- 成员可分配采购员、仓储员、销售员、收银员岗位，配合现有质管和财务角色办理交接；岗位变更后撤销旧会话，需重新登录。原管理员和业务操作员能力保留。
- 库存岗位交接：仓储与质管从原单办理调拨、盘点、运输短少和隔离品处置；工作台新增损失与处置4类待办，迟到货物收齐后仍保留遗留损失申请，核对后取消。
- 三类退货按岗位从原单申请：采购员办理采购退货、销售员办理批发退货、收银员办理零售退货；仓储登记客户退回品隔离收货及拒收交还，质管独立复核过账，财务核对原核销和退款。控制库c0016为已有岗位补权，受影响账号需重新登录。
- 平台按清单开通空白企业、首个主体 / 仓库 / 库位和首批成员，支持失败后原清单恢复及并发重试；两库资料齐备后启用，不复制演示库存。当前为本机平台工具，身份需预先建立；企业登录后继续原建档、期初、采购与批零流程。
- 企业工作台集中显示采购、批发、零售、退货、调拨、盘点、质量处置及期初开账的32类业务待办，按主体、环节、单号、往来单位或仓库名称查找，进入原单继续办理；返回保留筛选，切换企业清除旧内容。期初新增待审核、待启用，可按清单凭据查找；调拨显示调出 / 调入路线，分次收货未结清继续保留待办；盘点支持待实盘、待审核、待过账，完成或取消后解除所选主体批次冻结；退货包括收货、验收、入库 / 出库、拒收交还和退款，采购 / 批发退款核对不代表应退欠款。
- 商品及 SKU、供应商 / 客户建档，主体资质统一审核、停用及按范围有效期控制；商品和单位可更正、续期，原有效资料保留到本次变更审核通过，支持对比和撤回。
- 包装版本建档与独立审核；采购、批发、零售按包装数量与单价开单，自动精确换算基本库存数量，保留历史版本和交易快照。
- 采购 / 销售 / 库存查询的商品、往来单位及仓库选项支持分页加载，解决超过 200 条时无法加载的问题。
- 尚未登记到货的采购单可修改供应商、仓库、商品行、包装数量与价格；保存后重新独立审核，保留版本、前后快照和操作记录。
- 采购制单 → 独立审核 → 分次到货 → 分次验收 → 合格部分入库；已审核未收余量可关闭，原到货继续验收入库，保留关闭数量及原因。
- 采购验收拒收品可在原到货单分次退回供应商，记录交接凭据；未入库保管随实物交接结清，不产生库存、成本和应付。
- 入库事务同时登记库存、成本、供应商应付、审计和 Outbox，支持幂等重试与并发防重复。
- 销售单在分配前可修改客户、仓库、送货约定和商品数量 / 价格；释放原信用占用，重新独立审核后按新约定发货，保留前后快照。
- 客户授信 → 销售制单 → 独立审批 → FEFO 批次分配 → 拣货 → 独立复核 → 销售出库。
- 出库同步扣减库存和成本、生成客户应收；支持部分发货、取消未发子单和关闭订单余量。
- 批发开单、改单、分配发货及零售建单直接查看所选仓库可售数量；批发按最低效期筛选，并可刷新后按可售量填入本次发货。保留订单未发余量，批发与零售共用同一预占规则。
- 从原销售单核对缺货，扣除本单已关联未入库采购后准备补货；选择供应商、核对进价后生成待审核采购单，持久保留销售来源。采购合格入库后返回原销售单，继续分配、拣货、复核和发货。
- 未付款零售与待拣货批发子单的超时预占自动回收；已收款、已拣货 / 复核占用受保护，保留原单及审计。
- 实体仓库及多库位维护、名称更正和维护历史；采购 / 调拨可选择新库位，库存查询显示库位编码与名称。
- 未使用实体仓库的期初清单 → 独立审核 → 一次启用，登记原有合格库存及成本；直接接入正常批发、零售、调拨和盘点。支持 CSV UTF-8 模板下载、批量预览、逐行纠错和核对后填入（单仓最多200行）。
- 同仓移库申请 → 独立审核 → 确认实物移动；原库位扣减、同仓目标库位增加，批次总量与成本不变，保留双向库存流水。
- 库存可用量查询、库存 / 成本台账及关联应收应付。
- 资金账户、实际收付款人工登记、分次 / 多单核销、撤销核销和作废错误登记；原始凭据与更正记录保留。
- 收款核销减少应收并恢复客户额度，结清逾期款后解除对应拦截；付款仅冲减供应商应付。
- 按原商品行部分采购 / 销售退货，可分次退回；销售退回实物隔离收货、独立验收、拒收交还；库存与成本回转、往来冲减、原款项退款和更正。
- 采购入库批次、批发出库子单可直接办理退货，查看累计已退 / 剩余可退、继续待处理申请及历史记录，办完返回原订单。
- 零售建单预占 → 实收现金与找零 → 批号数量核对 → 库存及成本出库；已收款待出库单支持恢复或实际退款取消。
- 已完成零售单按原行分次退货 → 隔离收货与独立验收 → 恢复库存及原成本 → 原现金账户退款；拒收后交还实物，原零售单展示已退货、已退款与待退款金额。

- 库存盘点建单并冻结主体批次 → 逐行实盘 → 独立审核 → 盘盈盘亏库存及成本过账并解冻；支持无差异结单、取消和拒绝，完整保留基准与实盘记录。

- 新增实体仓库 → 同主体批次调拨申请 → 独立审核 → 发出进入专属在途库位 → 分次合格 / 隔离收货；成本池总量总额保持不变。

- 调拨短少按原行申请 → 独立审核 → 在途损失核销；同步扣减在途数量与批次成本，实收加已核销损失结清原调拨，保留两类独立事实。
