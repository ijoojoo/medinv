# 基础资料三栏与固定工具箱实施与验收

日期：2026-10-21。版本：0.35.0。业务库 b0054 / 控制库 c0017，102 张强制 RLS 表，192 条 API 路径；无数据库迁移、依赖或岗位权限新增。

本次按用户“所有基础信息／资料页面”的范围实施，覆盖资料菜单下的商品档案、往来单位、职员资料、仓库与库位、数据字典。参考桌面附件《往来单位_固定工具箱_优化版.html》及配套设计说明，复用实际接口和已有主题，不导入原型演示数据。企业设置、业务单据和质量台账的布局不在本次改造范围。

## 页面和入口归属

| 页面 | 左侧范围 | 中间资料 | 右侧固定工具 |
| --- | --- | --- | --- |
| 商品档案 | 原有品类树 | 查询、正式资料和跨品类固定字段槽位 | 修订、刷新、新建、审核、历史、附件、信息卡、复制编码、列设置、导入／导出 |
| 往来单位 | 全部、供应商、客户、供销双向 | 基本、经营、质量、经营范围与准入、医保、追溯、第三方对接 | 修订、刷新、新建、主体审核／停用、历史、附件、信息卡、复制编码、列设置 |
| 职员资料 | 全部、在职、离职 | 列表与只读档案，明确进入修订后显示表单 | 修订、刷新、新建、历史、复制编码 |
| 仓库与库位 | 全部仓库及当前查询范围的仓库 | 仓库身份、库位查询与选择 | 修改名称、刷新、新建仓库／库位、修改所选库位、历史、复制编码 |
| 数据字典 | 一级分类 | 字典页签、字典值及引用信息；修订后可维护配置 | 修订、刷新、历史、全局搜索、复制字典编码 |

往来单位原入口迁移：联系信息和简称维护进入右侧“修订资料 → 经营信息”；身份及资质修订进入同一入口的基本信息分区；证照和经营范围也在修订任务内维护。原中间变更记录页签、扩展资料跳转卡片、正文底部操作排、标题信息卡按钮均已移除。证照字段与有效期情况仍在中间，原件预览／下载统一由“证照附件”承接，上传和关联版本仍在明确的证照编辑任务内。

每个模块使用一份稳定工具配置，折叠与展开共用动作键；换资料页签不会重排菜单。不可执行的工具保留位置和原因；权限继续由服务端验证。列表的查询、分页、打开详情属于导航，仍放在内容区。表单保存、取消、提交及错误提示保留在具体任务中。

## 布局和任务状态

公共组件为 `MasterDataLayout.vue`、`MasterToolMenu.vue`、`masterTools.ts` 和 `masterDataLayout.css`。桌面左右展开栏共享 208px 宽度变量，1920px 以上统一为 216px，折叠栏 60px，间距 12px；资料工作区居中最大 1720px，不无限拉宽。业务和报表继续沿用原宽度策略。

低于 1280px，展开工具箱使用带焦点约束的覆盖抽屉；低于 900px，范围导航移到上方，正文和窄工具条保留可用空间。宽表在自身容器滚动；小字段按容器宽度换列。左右栏随内容滚动保持可达，不采用固定演示高度。支持减少动态效果偏好。

首次进入工具箱默认折叠。展开状态保存在当前模块组件会话，切换模块页签和资料页签不重置；关闭模块或切换租户／经营主体后重新初始化，不跨组织复用草稿。工具展开不重建资料，也不重新请求详情。缩窄窗口时只允许当前活动模块显示覆盖工具箱，后台模块保留展开偏好但不会弹出。禁用原因支持屏幕阅读、悬停和点击／Enter提示，状态变化不增减按钮行高。

往来单位复杂身份修订复用完整表单，其他分区在宽任务抽屉内维护；联系资料保存立即生效，身份、证件、范围仍随主体一次审核。离开、关闭、切换修订分区使用既有保存／放弃／继续编辑保护；取消身份修订回到原资料页签。历史和附件为只读查阅，信息卡继续使用原组件。窄屏工具面板先关闭再进入任务，避免两个焦点约束同时争抢焦点。

## 正式资料、待审核资料与接口

商品浏览使用已有 `active_values`，进入修订才使用 `values`；往来单位浏览使用已有 `active_record`，身份修订使用可编辑记录。状态区明确显示资料状态、实际版本和待审核提示，未审核的新档案不标为已生效。

两个读取响应补充了正式视图，沿用原租户、主体和资料读取权限：

- 往来单位证照列表增加 `active_items`，保留原 `items` 供修订使用。
- 经营范围响应增加 `active_results`，按正式范围和正式证照计算当前条件；原 `results` 保留待审核预检。只读范围的证件编号也使用正式证照，避免混用续期中的编号或日期。

职员列表增加可选 `staff_status` 参数（空、ACTIVE、LEFT），在服务端先筛选再分页，保留名称查询、主体隔离和原有列表行为。OpenAPI 已同步。现有保存、幂等、版本冲突、独立复核、库存和交易准入语义保持不变。
