# 仓库与库位操作指引（0.15）

## 建立收货位置

1. 以 demo.owner 登录，进入“资料 → 仓库与库位”，确认经营主体。
2. 新仓库使用“新增实体仓库”，填写仓库编码、名称和首个库位编码。首库位名称先默认使用编码。
3. 已有仓库点击“管理库位 → 新增库位”，填写本仓唯一编码、库位名称及维护原因。新库位初始无库存。
4. 已有库位可“修改库位名称”；仓库可“修改仓库名称”。均需填写原因，详情保留前后值及维护人记录。

库位例如编码 RECEIVE-02、名称“常温采购收货区”。名称用于现场辨认，不自动授予温控或药械经营资格。仓库、库位的编码和归属不能通过改名修改。

## 接入采购、调拨与库存

采购入库：按原采购流程建单和独立审核，登记到货时选择新库位；独立验收并入库后，库存登记在所选库位。已经打开的采购页应刷新后取得最新库位选项。

仓库调拨：新建调拨时选择调入仓库及新库位，按原流程独立审核、发出、登记到货。一个调拨单仍只有一个目的库位；已有在途单改库位名称不改变其目的库位 ID。系统在途仓由调拨流程维护，不在资料页提供人工操作。

库存查询：选择经营主体、仓库和商品，结果显示库位编码及名称。数量只能通过采购、销售、退货、调拨、盘点、质量处置等业务改变，资料改名不转移库存。

## 核对示例

建仓 WL-验收，首库位 DEFAULT，再新增 RECEIVE-02 / 常温收货二号位。向新库位采购入库 10 件，随后将名称改成“常温采购收货区”。库存仍是原余额 ID、RECEIVE-02、10 件；成本和台账没有新增过账。维护历史显示旧名称、新名称、原因及操作人。

## 异常与权限

- OWNER / ADMIN 可维护；只读成员可以查询库位和维护记录，不能保存。
- “资料已变化”表示其他人先完成修改，请关闭表单、刷新详情，核对后重新操作。原表单网络失败时可直接重试，不重复建立库位。
- 重复编码须核查原仓库 / 库位，不通过不同名称绕过。编码区分大小写，建议企业统一编码规则。
- 主体已停用时不能新增或改名；重新启用按既有主体管理流程处理。
- 历史库位未命名时显示编码；历史种子可能没有建档记录，不补造审计。

本轮提供名称与新增维护；停用、删除、库位合并、跨主体迁移及批量导入尚未开放。管理页每页 50 条；业务选项仍有当前容量上限，超过会提示，未完成大规模检索优化。
