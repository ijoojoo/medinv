# 资料修订操作指引（0.14）

用于同一商品或同一往来单位的资料更正、资质续期。入口：“资料 → 商品档案 / 往来单位 → 资料详情 → 修订资料”。

0.25 更新：新建和修订使用整页布局，详情分为基本、经营、医保及各平台卡片。身份、资质和核验档案变动继续重新审核；推荐级别、ABC / 双 ABC、助记码、单位简称、日常联系人、电话和收货地址在经营卡片直接保存留痕，不改变资质状态。资料列表可按状态、类别或供应商 / 客户身份筛选，详情返回保留查询；商品和单位的对接编码单独管理。详见[基础资料与对接编码](基础资料与对接编码.md)。

## 操作

1. 按名称或编码找到档案，打开详情，核对当前资料与资质有效期。
2. 点击“修订资料”，填写更正内容及修订原因。可编辑商品名称、生产企业文字、规格说明、批准编号、资质日期及药品分类；单位可编辑名称、许可编号、资质日期及经营类别。
3. 点击“保存修订并重新送审”。资料立即变成待审核，原批准结论失效。编码、商品类别、SKU、基本单位、数量精度、信用代码和单位类型等身份字段固定。
4. 由具有审核权限且未参与本轮修订的人员核对前后变化、资质及凭据，填写核验凭据编号和说明，再提交审核。建档人也不能审核通过自己的档案。
5. 审核通过后，依赖该资质的原业务可以按原单继续；若其他条件也不满足，仍需按对应错误处理。修订不自动取消订单或预占，不重新收款，也不改动既有库存和成本。

演示：`demo.owner` 修订，独立浏览器会话的 `demo.quality` 审核。QUALITY 默认只可审核，不能修订；VIEWER 只能查看。当前版本未新增权限，刷新管理端即可使用。

## 变更记录

详情中的“变更记录”标签显示建档、审核、停用、资质修订和经营信息更新历史，修订记录展示字段的前后值及原因。可展开查看审核凭据、说明和操作人 ID，每页最多 50 条。资料使用整页卡片布局。旧种子档案可能没有原始建档记录。

再次打开详情或点击“刷新资料详情”会读取最新版本。多人同时编辑时，后提交者遇到版本冲突，应重新读取资料并核对别人已保存的变化，不要覆盖。没有实际变化的修订会被拒绝。

## 对进销存的影响

- 待审商品或单位会被既有资质检查拦截，包括相关采购到货 / 入库，以及销售和零售后续资质检查。正常收付款、更正和允许处理异常库存的流程仍遵循各自规则，并非全系统停用。
- 已收款待出库零售单不会丢失原付款。审核通过后恢复原单，或走原单退款取消，不能重复收取现金。
- 已过账商品、包装及金额快照保留。历史页面若采用当前档案名称关联，可能展示更正后的名称；变更记录可用于核对名称差异。
- 药品只有审核通过的 OTC 可进入当前零售流程。把处方药标成 OTC 必须有真实分类依据；本功能保存人工核查结果，不自动判断药品类别。
- 单位经营范围缩减后，即使审核通过，也可能无法继续处理已不在范围内的药械业务。信用额度、应收应付不会因修订自动调整。

## 当前边界

资质修订用于更正同一档案，不能替换库存实际品种或更换法人身份。错误身份、不同包装计量或不同商品应按对应建档 / 后续专门流程处理。没有保留原批准版本并行营业的“待生效副本”；资质修订保存后进入待审，请安排好审核人员。多人在待审期间连续修订资质，所有参与者都不能批准；停用也不能清除这一限制，独立审核通过后开始新的修订轮次。日常经营信息按白名单直接保存留痕，不新增本轮资质修订人，不改变原有审核状态。

暂不支持自动证照核验、附件、批量修订、自动续期、回滚到历史版本、商品类别 / 基本单位变换或单位身份合并。依据仍是人工核查及记录编号。正式升级须暂停写入，迁移并统一服务版本后恢复；当前为开发验证版。
