最新实现：品牌、一级分类、企业和账号合并于48像素顶栏；点击分类展开模块菜单，Escape关闭，左右键切换分类、向下键进入菜单。下方36像素工作标签承载模块与独立草稿，不再保留常驻二级菜单。采购与销售草稿按ID区分，可同时打开，详情及草稿均可经独立地址访问。以下保留模块归属，早期布局说明以此段为准。

当前视觉：顶栏使用与清朗蓝 / 青碧 / 雅紫主题对应的彩色背景，白色导航文字、浅色选中背景和底部标记；主题、企业和账号留在同一行。保留48像素顶栏和36像素工作标签，不增加标题栏。桌面导航15像素，正文按系统中文字体呈现，表格主文字13像素；表头、辅助文字、焦点框使用统一主题色与中性色。窄屏保留两行顶栏和导航横向滚动。

资料列表筛选区使用浅色底，商品 / 单位身份摘要与卡片标签形成独立层级；字段信息使用紧凑分栏，价格和经营表单统一间距，保存区以细线分隔。主要内容的表格、边框、圆角和阴影统一。新内容样式限定于管理页面，零售工作区内部布局保留；单据明细沿用自身密度和滚动规则。主题选择仍在本浏览器保存，不改变业务内容或权限。

页面内容宽度已按业务/报表、资料、表单分为2560/1440/1120px上限，均在可用工作区居中；窄屏不设强制最小宽度。数据字典外层重复标题已移除，搜索位于内容栏右侧。详见[布局验收](页面宽度与紧凑工具栏实施与验收.md)。

## 实现与接入规则

- `apps/admin-web/src/navigation.ts` 是唯一导航配置，定义分组标识、中文名称、页面标识、图标及读取权限；`App.vue` 的页面标题和所属分类也读取此配置。
- `BusinessNavigation.vue` 先过滤权限，再移除没有可访问条目的分组。预留分组使用空列表，不展示不可点击占位菜单；服务端授权仍独立执行。
- 顶部第一行为工作台及主要业务分类，第二行展示当前分类的模块入口；不再使用左侧折叠菜单。点击分类进入本次会话最后访问的可用模块，初次优先同名页面（如库存查询），否则进入首个授权模块。返回同一分类不会产生跨企业的记忆；企业、账号或上下文代次变化重新建立导航状态。
- 两行菜单支持键盘左右方向键、Home/End移动焦点，Enter/空格激活。窄屏在各自导航行横向滚动，保留文字；桌面顶部导航固定，窄屏恢复正常文档流。当前分类、当前模块均标明选中状态；切换模块回到页面顶部。
- 内容区展示“工作空间 / 分类 / 页面”，工作区使用原左侧菜单占用的宽度。统一较紧凑的标题、间距、表格行高和边框色；工作台以常用入口和业务待办为主，企业主体授权信息折叠展示。常用入口同样按权限过滤。新增页面需同时接入实际页面组件和读取权限；只修改菜单配置不会产生业务功能。

历史验证：0.11 的菜单分组已通过键盘折叠、当前页、分类路径及 390 像素窄屏访问设置检查；0.16 全站 31 项浏览器测试通过，保持含质量模块的八个可访问分类，按角色过滤写入操作。

0.15 将仓库与库位基础维护放在“资料”，保留调拨页的新建仓库快捷入口；有 inventory.read 可读取，只有 warehouses.write 可以新增及改名。页面懒加载。

0.16 包装维护位于“资料 → 商品档案 → 资料详情”，不新增顶级菜单。开单单位选择直接置于采购、批发、零售商品行；收货、出库、退货与库存显示继续采用基本单位。

0.21 增加“库存 → 期初库存”，按 `inventory.read` 展示，制单 / 审核 / 启用分别受 `opening.write/review/post` 控制；本轮全站 35 项浏览器测试通过。

本轮仅调整导航与共享视觉样式，并修复采购/批发录入税率的回车行为；单据录入布局的进一步调整待与用户讨论确定。保留原业务路由、岗位权限、企业隔离和原单跳转。

本轮验证：3项新增导航场景最终通过，覆盖桌面与390像素窄屏、键盘访问、分类模块记忆、企业切换重置和只读权限；与待办原单跳转、登录/成员、录入等相关检查合计11个不同场景均有通过结果。记录见`artifacts/horizontal-navigation-browser.json`及`artifacts/horizontal-navigation-browser-final.json`，截图见`artifacts/horizontal-workspace-desktop.png`、`artifacts/horizontal-inventory-desktop.png`、`artifacts/horizontal-mobile.png`与`artifacts/horizontal-sales-1366.png`。前端类型、格式、构建及本机运行核对通过。
