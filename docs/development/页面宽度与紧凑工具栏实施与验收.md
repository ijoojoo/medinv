# 页面宽度与紧凑工具栏

2026-10-21，0.29.1。本轮按用户截图调整页面宽度与重复标题区域；业务迁移仍为 b0049，控制迁移仍为 c0017，不需要数据库迁移。

## 布局规则

| 页面类型 | 当前范围 | 宽度规则 |
| --- | --- | --- |
| 业务、报表与工作台 | 采购、销售、零售、库存、财务、退货、质量作业/记录、工作台；独立单据草稿与原单 | 随可用工作区铺开，超宽屏最大 2560px，居中 |
| 资料与配置工作台 | 商品、往来单位、数据字典、仓库、商品字段设置、经营范围与准入 | 最大 1440px，居中 |
| 表单与个人设置 | 职员、企业设置、审批设计、成员权限、界面操作、消息 | 最大 1120px，居中 |

宽度包含外层内边距。小于上限时使用实际可用宽度；不设置让整页溢出的固定最小宽度。表格、分类导航和页签按自身内容横向滚动。侧栏模式以扣除左侧导航后的工作区计算居中，切换模块时即时应用所属宽度。独立草稿和原单始终使用业务宽度，不继承上一次打开的设置页宽度。

规则集中在 `navigation.ts` 的 `widthForPage`，由 `App.vue` 外层主内容区应用，样式在 `appearance.css`。新增模块应按业务性质归类，避免每个页面单独设置互相冲突的宽度。

## 顶部空间与功能保留

- 数据字典删除截图红框中的独立页标题、说明及面包屑；内容区内重复的“字典管理 / 分类”路径也去掉。分类侧栏和字典内容直接跟随工作标签显示。
- 全局搜索移至分类内容栏右侧，保留点击搜索、Ctrl/Cmd+K、结果定位；编辑抽屉、启停、排序、保存和变更原因继续使用原逻辑。
- 资料、设置页面采用更紧凑的工具栏，操作按钮可随宽度换行，版本、记录身份和必要业务说明继续显示。
- 去除商品、往来单位、字典页面内部重复的 `main` 元素，避免全局主区样式产生多层边距；页面只保留一个主要内容语义区域。

## 验证

宽度专项覆盖 1920px 普通桌面、3440px 超宽屏及侧栏布局；在 1366、768、390、320px 下逐页检查字典、商品、往来单位、企业设置、职员、消息、采购和质量记录。除浏览器根节点外，也检查主内容区实际滚动宽度，避免用外层裁切掩盖溢出。实际检查结果与原功能回归见[本轮验证清单](页面布局验证-20261021.json)。

结果：10个浏览器场景通过（2项布局专项、4项商品/往来交互、3项独立单据草稿、1项管理功能联合验收），14项接口契约/部署工具检查通过；前端类型、生产构建和改动文件格式通过。六项本机服务就绪，运行镜像与源码一致，Linux容器180条API路径及方法、双库就绪和预占回收扫描通过。本轮未运行整个项目全量测试。
