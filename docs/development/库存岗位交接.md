# 库存岗位交接

版本0.24追加交付，2026-10-16。沿用原调拨、质量处置、盘点单据和仓储、质管岗位。

## 工作分工与入口

| 环节 | 经办岗位 | 后续交接 |
| --- | --- | --- |
| 调拨申请、实物发出、分次收货 | 仓储员 | 质管独立审核；按实际到货区分合格与隔离 |
| 运输短少申请、迟到货物后取消遗留申请 | 仓储员 | 质管审核、核销真实损失 |
| 自有隔离品放行或报损申请 | 仓储员 | 质管独立审核、确认处置过账 |
| 盘点建单、实盘提交 | 仓储员 | 质管独立审核、差异过账或无差异结单 |

工作台新增“在途损失待审核”“在途损失待核销”“质量处置待审核”“质量处置待过账”，合计30类待办。可按原调拨单号、损失单号、质量处置单号或仓库名称查找。查看损失待办会打开父调拨并直接展示本张损失详情，不受损失列表当前页影响；查看质量待办直接打开本张处置单。返回工作台保留筛选并重新查询。

读取沿用transfers.read或quality.read，看到待办不代表能操作。仓储岗位不具备损失、处置和盘点的审核/过账权限；即使组合质管角色，也不能审核或过账自己经办的这些单据；只读成员可核对进度，不能提交。切换企业或权限上下文后重新建立页面，避免沿用原企业入口。本轮未增加权限码、角色或数据库迁移，仍为b0026/c0016；更新核心服务和管理端即可。

## 实物与账务顺序

1. 仓储申请，质管审核，仓储核对实物后发出。申请与审核不预占；发出后数量转入在途，仍属于自有库存和成本。
2. 收到多少登记多少。合格收货进入可售库存，异常实物登记隔离。短少继续保留在途，不能用报损申请代替实收记录。
3. 已核实短少由仓储从原调拨发起损失申请，质管独立核查、核销。申请和审核均不扣数量或成本；正式核销才扣减本单在途和当前批次成本。未结在途继续留在收货待办。
4. 若申请后找到迟到货物，按实物收货。父调拨即使已经收齐，旧损失仍保留在审核/核销待办，按原记录取消或拒绝。系统不因父单收齐自动删除申请；核销条件不满足时继续保留待办，不能再次扣减已到货数量。
5. 自有隔离品另建质量处置单，按复验结论放行或报损；审核不改变库存，过账后放行才增加合格量，报损才减少库存及成本。原采购应付和销售应收不随库存处置自动冲减。
6. 在途、预占等处理完成后开始盘点。所选主体批次在其它仓库也被冻结，只有所选库位参与差异调整。提交或审核通过后仍冻结；正式过账或取消才释放，无差异也须结单。实盘人与制单人不能审核、过账本人经办的盘点。

不要把损失、隔离处置和盘点当作互相替代的调整入口。前者核对本单运输在途，中者处理已登记自有隔离实物，后者依据实际盘点记录调整指定库位。

## 可重复验收

管理端执行 `pnpm run test:inventory-jobs`，通过平台开通独立企业，使用管理员、仓储、质管、收银、只读五个真实登录身份。原采购入库经正式接口准备，库存作业经正式命令和原单页面办理；不直接写业务库。

验收采购10件，调拨8件后合格收4件、隔离收3件、核销损失1件；隔离品放行2件、报损1件。再调拨1件并申请损失，后来实际收齐，取消遗留损失；目的仓7件实盘为6件，独立过账后来源仓1件、目的仓6件、在途0件，总计7件、成本80.528元。采购应付仍130元，无新增应收或资金流。盘点期间跨仓零售受阻，结单后恢复可售，再取消未收款验证单。
