# 采购入库操作指引（更新至 0.20）

0.16 补充：开单可选择已审核包装，数量与含税单价均按所选交易单位填写；收货、验收、发货、交付、退货仍按基本单位填写。以下旧示例默认基本单位，包装示例见[包装换算操作指引](包装换算操作指引.md)。
管理端：<http://127.0.0.1:5173>。本机账号密码在项目 `.cache/演示账号.md`；请使用虚拟资料测试。

使用两个独立浏览器会话（例如普通窗口和无痕窗口），分别登录 `demo.owner` 和 `demo.quality`。两边都选择“安心药械批发 · 演示”。一个浏览器中切换账号后，原账号会话不能继续复用。

## 1. 管理员建档

在“商品档案 → 新建商品”填写编码、名称、类别、生产企业、规格、批准 / 注册 / 备案编号、SKU 编码、基本单位、数量精度和有效资质日期。每次测试使用新编码。

在“往来单位 → 新建往来单位”选择经营主体，填写供应商资料、经营类别及资质有效期。客户也可在此建档，用于批发销售。

保存后均为“待审核”。管理员可以查看资料，但不能审核通过自己建立的档案。

## 2. 质量审核员审核资料

进入对应资料列表，打开“资料详情”，核对字段，填写核验凭据编号与审核说明，再“提交审核”。凭据编号目前是人工档案索引，不是已上传的附件。

只有已审核且资质当前有效的商品、供应商才出现在采购选择项中。初始化库存使用的旧演示商品没有完整采购资质，请通过上述步骤新建测试商品。

## 3. 管理员制单，审核员审批

管理员在“采购入库 → 新建采购单”选择供应商与仓库，添加商品行，填写数量、含税单价和税率，保存采购单。金额单位为人民币元，数量按所选交易单位录入（默认基本单位）；不要输入千位逗号或科学计数法。

审核员刷新采购列表，打开对应采购单，填写操作说明并审核。制单人自己不能审批。首笔到货前可以修改采购单，保存后重新独立审核；已有到货的采购约定保持不变。

## 4. 管理员登记到货

打开已审核采购单，选择“登记到货”，填写随货单号、运输及随货核查、商品、货位、实收数量、批号、生产日期和效期。可多次到货、同一商品拆批号；累计到货不能超过采购数量。

此时只是保管记录，库存查询和应付尚不增加。采购单“已收齐”只表示订单全部到货，不表示全部合格入库。

## 5. 质量审核员分次验收与入库

刷新单据，在对应到货记录点击“登记验收”，填写本次合格、拒收数量与验收依据。例：到货 10 个，填合格 6、拒收 2，剩余 2 自动保留待验。收货人与验收人必须不同。

保存验收记录后，点击“合格入库”，核对弹窗中的商品、批号和数量，再“确认入库”。只会计入这次验收的合格数量。已入库单元显示“已入库”；剩余待验可另行登记验收。

拒收数量留在未入库保管记录中。实物交接给供应商后，在原到货记录点击“拒收退回供应商”，填写本次退回数量、交接凭据号、供应商接收人或承运方及说明。可以分次退回；仅允许退回已拒收且未退回的数量，保存后不可直接修改。需要采购收货权限，质量审核员不能仅凭验收权限登记交接。

退回后“拒收已退”增加、“未入库保管”减少；原拒收、合格、已入库和采购已收数量保持不变。订单关闭后仍可处理原拒收品。已合格入库的商品通过“采购退货”处理。

示例：到货 10 个，6 个合格入库、2 个拒收、2 个待验，未入库保管为 4。拒收品分两次各退回 1 个后，保管剩余 2；剩余 2 个验收合格并入库后，累计入库 8、拒收已退 2、保管为 0。拒收退回自身不产生库存、成本、应付或退款。

## 6. 核对库存与台账

“库存查询”选择同一主体、仓库和商品后查询，可核对账面和可用数量。“库存台账”显示每条已过账的数量、成本及关联应付。

对于 6 个合格品、含税单价 13 元、税率 13%，当前策略记库存 +6、成本 +69.03 元、应付 78.00 元、税额 8.97 元。关联应付为整次过账金额，多行显示同一过账时不可重复汇总。

## 常见提示

| 提示 | 处理方式 |
| --- | --- |
| 需要另一成员审核 / 验收 | 使用有对应权限的独立成员账号 |
| 资质未生效 / 已过期 | 核查资质档案；不要伪造日期绕过校验 |
| 单据版本变化 | 刷新核对已保存记录，避免重复新建 |
| 同批号日期或效期冲突 | 核实批号及原始凭据，不通过更改拼写绕过冲突 |
| 系统繁忙 / 结果待确认 | 保留原页面和输入重试；写入会复用当前请求幂等键 |
| 会话失效 | 重新登录，先查看单据是否已经成功保存，再决定下一步 |

0.5 已补充付款登记与应付核销，见[收付款核销指引](收付款核销操作指引.md)。已过账数据没有直接修改入口；0.6 已补充按原过账批次的整批退货与退款，见[退货退款操作指引](退货退款操作指引.md)。已支持按原商品行分次部分退货；完整冲销仍待后续，当前为开发验证环境。


## 0.18：关闭未收余量

已审核但尚未收齐的采购单可以关闭全部未到货余量。关闭后停止新到货，原待验、拒收保管、合格待入库和已入库记录继续保留；后续验收与入库沿用原约定，不改变已收货金额。入口在采购详情，详细数量示例见 [采购余量关闭操作指引](采购余量关闭操作指引.md)。草稿仍用取消，已收齐无需关闭。


## 0.19 补充：到货前变更

尚未登记到货的待审核 / 已审核采购单可修改供应商、仓库及商品行，保存后需重新独立审核。原制单人及本轮修改人员不能审核通过。原订单号保留，修改前后快照及审核记录可查看；已有到货单不支持改写。详见[采购变更操作指引](采购变更操作指引.md)。
