# 核心按钮与折叠扩展菜单实施与验收

版本0.37.0，2026-10-21。按用户本轮要求实施，覆盖现有基础资料、业务功能与报表页面；无数据库迁移，b0054/c0017、102张强制RLS表、195条核心API路径保持不变。

## 操作位置

| 区域 | 保留的内容 |
| --- | --- |
| 资料列表主工具栏 | 新建商品/项目、新建往来单位、新增职员、新增实体仓库 |
| 资料详情主工具栏 | 修订、商品质量审核/停用、往来单位主体审核/停用 |
| 仓库详情及库位行 | 新增库位、修改仓库名称、库位行直接修改名称 |
| 字典主区域 | 搜索全部字典、修订字典、直接新增字典值；保存与取消仍在编辑任务中 |
| 业务主区域 | 原有新建、增行、保存、提交、审核、收货、验收、入出库、收付款等办理操作 |
| 报表主区域 | 筛选、查询、重置、汇总/明细/图表切换、导出、单号下钻、关联记录和图表控制 |
| 右侧扩展功能 | 资料刷新/变更记录/附件/信息卡/列设置/批量导入导出；业务通用显示设置、说明和复制页面链接；报表另有字段配置 |

扩展功能不承载单笔新建、修订、审核或过账。操作可用性沿用原权限、忙碌状态、未保存修改保护和业务状态校验；商品监管资料、往来单位证件与范围仍随主体统一审核。

## 交互与布局

右侧首次进入默认折叠，只展示“扩展”按钮，不占据整列菜单。桌面展开为208px菜单；1280px以下以右侧抽屉展开，避免压缩表格。菜单可用Escape收起；窄屏选择功能时先关闭扩展抽屉，再打开目标任务，避免双重遮罩与键盘焦点丢失。

切换经营主体、账号或工作上下文重置业务扩展菜单；缓存且隐藏的模块不会打开扩展抽屉。显示设置通过对话框打开，不离开当前业务页；页面筛选与未保存内容保留。复制链接不包含未保存编辑内容，打开仍需要登录及相应权限。

业务与报表最大宽度2560px；基础资料最大1720px，其他设置继续采用对应限宽。宽度按当前页判断，已缓存的隐藏资料页不再影响当前报表或设置页。窄屏整体自适应，宽表格在内容区域内滚动。

字段配置按原有账号/企业/经营主体/记录类型/视图隔离保存。图形化报表中字段配置入口说明需先切换至汇总或明细；导出和图形统计口径保持0.36.0实现。
