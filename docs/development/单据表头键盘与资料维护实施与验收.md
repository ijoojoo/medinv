日期：2026-10-21。版本：0.33.1。业务库 b0054 / 控制库 c0017，102 张强制 RLS 表，191 条核心 API 路径；没有新增接口、数据库迁移或运行依赖。本增量在0.33.0质量记录交付后推进N07首批开单体验。

## 操作变化

采购、销售的新建和改单页面共用表头键盘规则：

- 普通 Enter：确认当前字段合法后进入下一项，最后一项进入首行商品。不会由表头原生回车意外提交整张单据。
- Shift+Enter：返回上一项；Tab仍按原生顺序移动。往来单位候选列表打开时，Enter继续先确认候选。
- 中文输入法组合期间的 Enter不跳字段或提交。销售最低剩余效期、账期通过键盘聚焦后选中原数值，便于直接替换；不合法数值按Enter仍留在当前字段。
- Ctrl+S仍保存编辑草稿；Ctrl+Enter正式保存；Ctrl+Shift+Enter在新建单据中保存并新建。改单页仍不提供连续新建。

右上角新增“维护往来单位”和“维护商品资料”。先保存当前草稿，再进入已有资料维护页面；维护完成后点击原单据页签返回。表头、商品明细和草稿备注保留，刷新也可恢复。资料仍按原权限、审核及准入规则维护；入口不会自动建档、审核或选入新资料。

草稿保存失败时保留输入并留在原单据，显示失败信息；不会在草稿未保存时跳走。草稿冲突或提交处理中不可进入维护。没有资料查看权限时不显示维护入口。

补修连续开单的异步焦点问题：沿用供应商/客户时，等待已选单位名称加载完成后才判断表头是否缺失。完整表头定位到首行商品；失效或读取失败的单位仍需要核对。用户已经开始另一个操作时，迟到的响应不抢走焦点。
