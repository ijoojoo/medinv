# 零售现金收银操作指引（0.9）

0.16 补充：开单可选择已审核包装，数量与含税单价均按所选交易单位填写；收货、验收、发货、交付、退货仍按基本单位填写。以下旧示例默认基本单位，包装示例见[包装换算操作指引](包装换算操作指引.md)。
入口：管理端 `http://127.0.0.1:5173/` → **零售收银**。从 0.8 升到 0.9 不新增角色权限；从更早版本升级后需重新登录。

## 准备

1. 由管理员建商品和供应商，质量员独立审核，完成采购验收入库，使商品具备可分配库存和成本。
2. 器械使用普通批次商品。药品建档时明确选择“非处方药 OTC”并独立审核；未知分类、处方药、特殊类别及序列号商品目前不开放零售。
3. 在“往来结算”建立同一经营主体的现金账户。银行账户不会出现在收银选项中。
4. 使用 `demo.owner` 或具备零售操作权限的成员售卖。待出库退款需要管理员或财务人员权限。匿名现金顾客不需要建立客户档案或授信。

旧演示库存可能只有种子余额，未经过资质与成本入账；请使用通过真实采购流程建立的测试商品。

## 正常收银

1. 选择经营主体，点击“新建零售单”。
2. 选择出货仓库，搜索商品名称或 SKU 编码，加入商品并输入数量、实际含税单价与税率。
3. 点击“建单并预占库存”，系统按先到期先分配原则选择批次，并计算应收金额。建单后的普通预占有效期为 15 分钟；超时停止收款，后台回收后重新开单；也可手动取消。
4. 点击“登记现金收款”，选择现金账户，填写顾客交付现金，核对页面显示的找零。实际收钱并找零后，勾选确认、填写说明、保存。
5. 单据显示“已收款待出库”。按交付批次取货，点击“核对并完成出库”，逐行录入实物数量和批号，填写说明后保存。
6. 显示“已完成”时，库存、成本及过账流水已同时更新。零售单保留原始商品、价格、数量、批号及现金记录。

示例：采购 10 件，销售 3 件，含税单价 20 元，应收 60 元；顾客交付 100 元，应找零 40 元。完成后库存为 7 件，零售现金净收为 60 元，不形成客户应收。若原采购未税成本为 115.04 元，本次出库成本为 34.512 元。

## 异常恢复与取消

- **尚未收款**：点击“取消零售单”，填写说明后解除预占。已过期的未收款单可由后台任务自动取消并释放，也可手动取消。详情显示自动处理时间，见 [预占回收操作指引](预占回收操作指引.md)。
- **已收款但未完成出库**：付款和预占保护会保留。商品冻结、批号错误等原因解决后重新核对出库，不要重复收款。即使刷新或重新登录，也可以在列表打开原单继续处理。
- **已收款且不再交付**：退款人员将本单净收现金实际退还顾客，再点击“登记退款并取消”，确认并保存。系统按原账户登记退款并解除预占。例如原交付 100 元、已找零 40 元，本次退还 60 元。
- **网络异常**：先使用原表单重试或刷新原单详情核对收退款记录。不要把重试当成新的现金交接；重试、退款与出库都有防重及版本检查。

已完成零售单不能使用“登记退款并取消”。请在原单点击“办理原单退货”，按原批次申请退货，完成隔离收货、独立验收及入库后再登记现金退款。支持多次部分退货，操作与核对示例见 [零售退货退款操作指引](零售退货退款操作指引.md)。

## 当前边界

现金记录是实际交接的人工登记，不执行电子扣款或银行转账。尚未支持现金日结、收银班次、会员促销、小票、医保、处方审核以及支付平台退款。原往来结算页面仍面向供应商 / 客户的账款，零售现金记录在零售单详情查看。

商品价格与税率由操作人核对录入。商品资料修订及旧药品分类补录尚未提供；不要假定旧药品自动具备 OTC 资格。

当前仍为开发验证环境，主流程验证优先；后续顺序见 [开发进度](开发进度.md) 与 [ADR 0008](../adr/0008-零售现金交易主链.md)。
