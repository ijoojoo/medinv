# 单据仓库检索实施与验收

日期：2026-10-21。版本：0.34.0。业务库 b0054 / 控制库 c0017，102 张强制 RLS 表，192 条核心 API 路径；无数据库迁移、运行依赖或岗位权限新增。本次完成 N07 的仓库检索增量，N07 整体尚未结束。

## 操作变化

采购和销售共用的单据编辑页（含改单）以仓库名称或编码检索，候选显示名称、编码和实体仓库标识。同名仓库按稳定身份选择；查询大小写不敏感，百分号、下划线等按普通文本处理。每页20条，可前后翻页。

输入关键词后使用上下箭头切换、Enter确认；再次Enter进入下一项，Shift+Enter返回上一项，Tab正常移动，Esc关闭候选。中文输入法组合期间的Enter不会选中或提交。重新聚焦已有选择后保持原仓库，包括原仓库不在第一页的情况；修改文字会立即清除原仓库身份，任意文本不能充当有效仓库。搜索失败保留输入，可重试。

刷新草稿、改单和连续开单按仓库ID恢复名称，等资料回填完成再恢复录入位置；用户已开始其他操作时不抢焦点。已停用仓库可回显名称，但不能作为有效新选择；无权访问、不存在或读取失败时提示重新选择，保留草稿原ID，不自动替换。正式保存继续由服务端重新检查仓库所属主体、类型和有效状态。

往来单位和仓库复用检索组件，保留原来供应商/客户权限和资质筛选，以及历史查询允许选择旧资料的行为。商品、往来单位审核和法规规则没有变化。

## 接口及实现

新增 `GET /api/v1/warehouses/lookup`，参数为 `entity_id`、`channel`（purchase/sale）、`search`、`offset`、可选 `warehouse_id`。按采购或销售读取权限与主体范围校验，业务库RLS隔离租户；仅提供实体仓库，不混入在途仓等系统仓库。一般检索排除停用；明确ID读取允许返回停用标记，供旧草稿识别。稳定排序为名称、编码、ID，每次至多读取21条判断后页。

编辑页不再额外获取采购/销售整批仓库和库位选项，改为按需检索和单ID回填。单据列表筛选仍按原机制获取它自己的选项，此次没有重写列表筛选。涉及文件为 `EntryReferenceLookup.vue`、两个薄封装、`DocumentEditor.vue` 和 `warehouse_lookup.py`；接口契约已更新。
