日期：2026-10-17。状态：已进入实施，独立工作区、编辑草稿、个人明细字段模板及首批CSV明细导入导出已接入系统；下文同时包含尚未实施的目标，实际范围及边界见《开发进度》。适用范围：先覆盖采购、批发销售的新建与改单，再迁移零售及必要的其他单据。已有业务能力保留，不扩大采购、分批、退货流程。

依据：用户提供的三张参考界面及本项目现有实现。已尝试连接参考系统，浏览器连接持续超时，未完成登录和实际交互核查；不能据截图推断其草稿、持久化或权限机制。参考站的账号、密码不写入文档、代码、原型或日志。

## 1. 推荐结构：单行顶栏、工作页签、独立单据页面

顶部48像素左右的一行合并品牌、业务分类、主题切换、企业切换和账号菜单。品牌及主操作使用统一主题色，减少装饰。采购、销售、库存、质量、资料等分类点击展开模块菜单；较长的库存菜单分为日常作业、查询两组，不让永久二级导航占据一整行。支持点击和键盘打开，悬停只辅助；Esc关闭菜单，不能关闭正在录入的单据。

导航下方约32像素工作页签承载当前打开的列表、单据和查询页。普通列表按模块复用页签；单据按草稿ID或正式单据ID识别，重复打开聚焦已有页签。多张新单据各自独立，名称优先显示往来单位，其次单据类型；显示未保存、已保存草稿、提交结果待确认等状态。页签过多时横向滚动并提供已打开页列表，不无限压缩文字，也不自动淘汰未保存页。

移除独立的大标题区、说明段、面包屑、重复企业信息以及装饰性card header。页面名称放在工作页签或紧凑工具条；必要业务状态和主体信息仍明确显示。企业与经营主体不是同一概念：企业选择放顶栏，单据所属经营主体放表头，已开始录入后不能静默切换其归属。

1366×768桌面以更多可见行、可读文字和持续可达的保存操作为目标，实际行数随表头、提示和字段换行变化，不通过缩小文字硬挤行数。当前顶栏48px、页签36px、采购表头常规一行32px输入；普通紧凑行40px，舒适模式按行内附加信息自然增高。较高窗口可同时显示12行，768px高窗口的长单据在明细内滚动。1920宽屏自然扩展。窄屏菜单及明细各自在区域内横向滚动，不撑宽页面。

## 2. 开单不依赖列表挂载

新建、编辑、查看均为有独立地址的页面，并复用同一单据组件；不是全屏弹窗，也不依赖底下的采购/销售列表存活。刷新或复制地址后重新鉴权并加载当前单据。示意：`/workspace/purchases`、`/workspace/purchases/drafts/{draftId}`、`/workspace/purchases/{orderId}/edit`；最终路由命名按实施统一。

从列表打开单据，记录来源工作页ID、主体、已提交的筛选条件、页码、排序、滚动位置及选中记录。返回时恢复原列表上下文；保存成功使关联列表失效并定点刷新，但不清空筛选或跳回第一页。新记录不匹配原筛选时，提示“已保存，当前筛选未包含此单”，提供查看该单，不擅自修改筛选。直接地址进入没有来源时，返回该单类型的默认列表。

从业务待办、销售补货、退货来源等打开，沿用各自业务来源标识与返回路径。来源上下文不作为授权依据，目标单据必须独立校验租户、主体和读取/写入权限。返回地址只能是已知内部路由，不能接受任意外部跳转。

切换工作页签不关闭单据，不丢失输入、当前行、列配置和滚动位置。关闭页签、切换企业或退出时，如果未完成持久化，给出“保存草稿后离开 / 放弃本次修改 / 继续编辑”；失败时留在编辑页。已经确认保存的草稿关闭不反复打扰。刷新/关闭浏览器使用持续保存及浏览器离开提醒，不能承诺崩溃、清理缓存、断电时绝不丢失。

## 3. 独立开单页布局

1. **紧凑工具条**：单据类型/编号、状态、来源入口；右侧导入、导出、字段设置、帮助。没有第二层重复大标题。
2. **表头**：常用字段一至两行排列；采购默认主体、供应商、收货仓库，销售默认主体、客户、出库仓库及收货信息。业务日期、备注等尚未入现有模型的字段必须连同服务端语义一起实现，不能只在页面加一个不保存的输入框。低频信息折叠，可由模板决定展开。
3. **明细工作区**：使用剩余空间，固定表头、可冻结商品列和行号、固定合计。单行默认只展示核心数据，当前商品的完整规格、厂家、包装换算及提示在行下详情或底部信息条查看，避免每行都放多段说明。保持重复商品独立行。
4. **固定底部操作区**：当前保存状态、条目数、含税合计与错误定位；保存草稿、保存单据、保存并新建。混合单位数量不能简单相加为“总件数”；数量按单位或商品汇总，金额币种明确。

明细只进行自身滚动，避免“页面滚动＋弹窗滚动＋表格滚动”并存。候选浮层可跨出表格并避开底部，不被容器裁切；光标跳格后只滚动必要区域，不能把工具条或保存区推走。

当前修复（2026-10-17）：常规桌面开单按窗口剩余高度分配明细，合计和保存区独立占位；焦点跳转与尺寸变化时避让表头、顶栏和保存区，保证当前输入框可见。窄屏/较矮窗口及展开附加内容时允许外层自然滚动。粘贴输入区内Tab插入制表符、Enter换行、Shift+Tab离开，保留选区替换和中文输入法保护。

## 4. 字段配置与模板

表头和明细分别配置。建立稳定字段标识，显示名是别名，不能改变接口键、计算含义或历史记录。企业默认模板、岗位模板、个人覆盖依次继承；首批先实现企业默认和个人覆盖，岗位模板按实际需求追加。按租户、账号、单据类型及新建/编辑用途隔离，提供恢复默认、另存模板、模板预览。配置保存到服务端并有版本，浏览器缓存仅用于提速。企业模板由配置权限管理，个人不能覆盖企业强制规则。

| 配置 | 规则 |
| --- | --- |
| 显示/隐藏 | 支持，但无可靠默认值的关键必填字段不可隐藏；隐藏只影响显示，不丢弃已填值。已有非默认值的隐藏字段在摘要或提示中可见。 |
| 排序 | 设置面板拖动排序，同时保留上下移动按钮供键盘/触屏使用；可支持表头拖列，均只改变视图顺序。 |
| 列宽 | 固定像素或剩余空间占比。先扣除固定列与冻结区，再按比例分配剩余宽度；设最小/最大宽度，超出可用空间时表内滚动，不压成不可录入。列边拖动改变为固定宽度。 |
| 字段名称 | 可改显示名称；配置中仍显示系统原名。例如“采购价”对应“含税单价”，不能隐藏其含税语义提示。 |
| 回车/Tab停留 | 可编辑字段独立设置，默认商品、数量、单价停留；单位、税率有合法默认值时跳过。鼠标仍可直接编辑，错误会强制定位，即使该列不在停留序列。只读列不参与。 |
| 格式 | 类型限定的格式选项：数量精度、金额千分位/尾零、税率百分比或小数、文本截断/换行、日期格式、对齐。编辑显示原始有效精度；格式不修改存储精度、税额规则或舍入算法。禁用任意脚本格式化。 |
| 固定与密度 | 冻结商品/行号等必要列；紧凑/标准行高；可选按完整信息换行。 |

“隐藏”“业务必填”“是否停留”是三个独立概念。选择一类器械等资料字段的条件必填仍由既有商品字段规则负责；单据字段模板不能取消法规/业务校验。产品主数据字段规则与单据录入模板分别管理，通过字段元数据引用，避免混成一个任意表单编辑器。

配置改变后不清空行、不改商品、不改数量单价。第一版不引入任意自定义公式、任意新增业务字段；先把已有字段真正配置好，新增业务字段按数据模型及接口一起扩展。

## 5. 键盘约定与多行处理

默认快速路径：**商品 → 数量 → 含税单价 → 下一行商品**。单位和税率在明细中可见但默认不占停留点，默认值来自明确的业务设置/商品信息，现有税率默认值不能被解释为所有商品都适用。默认缺失、单位待选择或字段错误时不能跳过。回车和Tab按配置序列移动；Shift反向。配置中至少保留商品、数量等必要停留点，防止所有字段跳过造成焦点循环。

下拉交互统一为：↓/↑打开候选并移动高亮，Enter确认当前候选并进入下一个停留字段，Esc只取消候选并恢复输入前值，Tab在有明确选择时确认后移动。无明确候选且输入未解析时留在当前字段提示。候选未打开时的Enter直接执行校验与跳格；无意按方向键不能提前改写业务值。税率支持百分比显示，底层仍存0到1的小数；例如选6%写入0.06。输入中保留明确的格式标识，避免6与0.06混淆。

候选打开时↑↓优先选择候选；Alt+↑↓用于同列跨行，不与候选混用。中文输入法组合阶段不拦截回车。键盘操作有可见高亮和正确的combobox/listbox语义，鼠标与键盘得到同样结果。

已实施的商品候选（2026-10-17）：采购/批发新建及改单共用五列候选（SKU编码、商品名称、规格型号、生产企业、基本单位），关键词按普通文本高亮，长内容可悬停核对，当前候选信息汇总在底部。沿用服务端每批20条、多关键词空格匹配、准确SKU编码优先及可选商品范围，不新增前端猜测或目录全量加载。↑↓在本批移动，PageUp/PageDown或上一批/下一批按钮翻批；回前一批定位末条，进入后一批定位首条，Enter确认当前候选并进入列模板的下一停留字段。失败可按Enter重试当前批，不误回首页。

商品检索文字未确认时Tab继续留在输入框提示；Esc恢复原商品与原数量价格，不隐式确认新商品。关闭候选、失焦、换词、组件销毁或账号/主体上下文改变会取消过期查询；连续回车等待同一个当前请求，只确认一次。输入法组合期间不发起候选查询或确认，组合结束后再检索。候选表头与翻批区保留，列表内部滚动；浮层按实际可用高度向上或向下展开，窄屏在浮层内横向查看列，不撑宽主页面。

沿用当前Alt+Insert插行、Alt+Delete删行与撤销、Ctrl+Enter保存；增加Ctrl+S保存编辑草稿。行末完成后进入下一已有行，最后一行才补一个空行；到达上限不产生多余行，不擅自合并重复商品。行使用稳定ID，拖列和插删不串值。空白尾行不提交，未完整行定位并解释原因。

首期保留现有50行限制，验证50行连续键盘、批量导入、改单、滚动及字段切换的实际体验。不直接宣称支持几百上千行；扩大行数时再一起检查服务端请求上限、查询批量化和明细渲染。列模板、草稿和导入均记录字段/结构版本，升级后用可控迁移，不静默丢字段。

## 6. 编辑草稿、正式保存与异常恢复

当前系统的采购/销售`DRAFT`对应已保存、待审核的正式业务单。新增“编辑草稿”必须与它区分：允许缺供应商、缺价格、缺商品的未完成输入，不生成业务单号、不进入审核待办、不影响库存、预占、应收应付。草稿归属租户、经营主体、创建人、单据类型；改单草稿还绑定原单ID和原版本。

持久化以服务端草稿为准：停止输入约1至2秒后增量或整体保存，Ctrl+S立即保存；界面只在服务器确认后显示“草稿已保存”。首期50行可整体快照，避免过早实现复杂协同补丁。保存有版本检查，同一草稿多窗口冲突时保留本地内容，提供重新载入或另存，不最后写入强覆盖。

浏览器恢复副本作为异常补充，按租户/账号/主体/草稿隔离并设保留期；明确标识“仅本机恢复”，不把本机成功写入等同云端保存。退出及切企业不能显示其他账号的草稿。未确认的商品检索文字可作为编辑内容恢复，但提交时必须重新确认合法SKU。恢复时重新核验权限、商品/资质、价格精度、包装版本及原单版本，不把旧草稿当作有效业务事实。

点击保存单据时执行完整业务校验并调用既有创建/修订路径；成功后草稿标记为已转单并关联正式单号。沿用幂等键和已有“提交结果待确认”机制：请求结果不确定时保留原不可变提交快照，先核实结果，不能直接换新幂等键再次下单。提交期间冻结编辑，防止草稿继续变化与提交快照不一致；失败恢复输入，不丢单。

### 2026-10-19 录入位置恢复

采购、批发销售的新建及工作区改单页记住最后操作的表头字段或明细行、列。切回单据页签、刷新当前草稿地址，或关闭已保存页签后在同一浏览器标签中重新打开草稿，均可继续原位置录入；恢复明细时沿用现有滚动定位，避免输入框被表头、合计或保存栏遮挡。

位置按租户、账号、经营主体和草稿分别存放于当前浏览器标签的 sessionStorage，有效期24小时。它只包含行标识、行序号及字段标识，不保存商品检索或业务字段值，不计入单据修改状态，不触发自动保存、不增加草稿版本。已保存内容仍以服务端草稿为准；未保存内容及版本冲突沿用原有恢复规则。跨设备、全新浏览器标签或关闭浏览器后的定位不在本次保证范围内。

优先按稳定行标识定位，因此行顺序变化不会定位到另一商品；原行删除后按原序号定位最近可用行；原列隐藏或暂不可编辑时回到该行可编辑字段，不擅自展开隐藏列。资料加载期间用户已经开始其他操作、打开对话框或切换页签，后台加载结束不会抢夺焦点；已转为正式单据或冻结的草稿不自动进入编辑。

验收：新增5项真实登录浏览器测试覆盖采购/销售20行草稿、双单页签切换、刷新和关闭重开、精度及未确认检索文字保留、纯定位不写版本、行移动/删除、隐藏列、慢加载，以及过期/非法/其他账号位置缓存。原草稿恢复3项、长表格和粘贴3项、连续开单4项回归通过，共15项不同用例。连续开单测试同步适配已存在的模块/记录页签和供应商/客户名称展示，业务保存和幂等断言保留。管理端类型、构建、改动文件格式检查通过；本机试用容器已更新，镜像与源码一致，无新增接口和数据库迁移。

## 7. 导入、导出与常用操作

当前实施范围（2026-10-17）：CSV UTF-8明细导入、按系统表头识别、SKU/单位/包装校验、逐行预览、追加/确认替换/编辑前撤销、错误清单及两种导出已接入采购/批发公共明细组件。每单50行、文件256 KB，固定模板版本1；完整导出不受显示名和精度设置影响，按显示列导出仅用于核对。复制行已接入新建与改单：按钮或 Alt + Shift + Insert 在当前行后复制，保留原值和隐藏字段、生成独立行标识并定位数量；最近一次未修改的新行可撤销，其他行修改保留。XLSX/XLS直接读取、表头导入和自由映射第三方列仍未实施。下文包含完整目标，不能将未实施目标视为已交付。
