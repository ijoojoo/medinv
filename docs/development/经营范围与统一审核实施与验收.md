# 经营范围、可配置准入与主体统一审核

日期：2026-10-21。版本：0.30.0；业务库 b0052，控制库 c0017，99 张强制 RLS 业务表，184 条核心 API 路径。

本次按用户确认的设计实施：经营范围放回往来单位，证件按范围提供经营资格；商品和往来单位的证件、批准编号、范围随主体一次审核。内置法规规则是可修改的企业默认值，不因内置而锁定。

## 1. 使用入口

| 入口 | 用途 |
| --- | --- |
| 资料 → 往来单位 → 经营范围与准入 | 维护供货/购货范围、器械管理类别、目录版本、允许与排除类目、关联证件和适用例外 |
| 往来单位 → 质量管控 | 维护证件原件、有效期、授权；查看变更对比并一次审核主体及变更 |
| 商品档案 → 维护 → 证件详情与维护 | 维护批准/注册/备案证件、原件、续期和版本关联；随商品审核 |
| 设置 → 企业设置 → 质量与准入 | 设置拦截方式、影响范围、证件校验要求及可修改的法规默认规则 |
| 经营范围与准入工作区 | 配置本企业经营范围，进行采购/批发准入试算 |

新往来单位不必填写一组虚构的“统一许可证编号、统一有效期”。采用范围管理时直接登记实际证件；旧字段为历史兼容保留。

## 2. 范围与证件怎么匹配

器械管理类别 I/II/III 与分类目录编码分开保存。例如“第三类、2017 目录、06”表示第三类中证件覆盖的 06 类；06 本身不代表第三类。商品也有管理类别、分类编码和目录版本。

范围支持多个类目、包含下级与排除类目。例如允许 06、排除 06-02，会匹配 06-01，但不会匹配 06-02、08 或 060；目录版本必须一致。药品范围沿用结构化经营分类匹配，不混用器械分类码。

一项范围可以关联多张证件，一张证件也可供多个范围引用。证件条件按“组间同时满足、组内任选其一”计算。只有该单位自己的、适用当前供货/购货用途的证件可用于判断。例外必须登记对应规则、依据及说明，随主体审核。

默认按品类控制：某张三类经营许可证到期，只影响依赖该证件的范围；其他具备有效资质的范围仍可使用。若同一范围存在另一个有效证件组合，可以继续满足条件。有效期每次交易重新判断，续期草稿不能提前恢复资格。

企业可选择：

- 强制拦截、仅提醒或关闭自动拦截；提醒与关闭仍保留实际不满足原因。
- 按品类控制，或在当前业务方向按整个单位控制。
- 是否核对本企业范围、是否保留旧资料统一有效期控制。
- 商品证件是否必需、证件类型及有效期要求、监管主体要求、哪些证件类型必须填写固定有效期。
- 原件凭据、授权联系人、单位证件有效期确认等资料要求。

已经显式停用的主体及无对应供销身份的单位，仍不能作为正常交易单位。这是主体状态与权限管理，不以关闭资质自动拦截来恢复。

## 3. 内置法规规则

首次提供九项可编辑模板：器械经营企业主体资料、二类经营备案、三类经营许可、器械注册人/备案人自行销售依据、器械医疗机构客户资质；药品经营企业主体资料、经营许可、持有人自行销售依据、医疗机构客户资质。

每项规则包含名称、启停、适用业务、单位身份、器械管理类别、证件组合、法规来源、条款、生效/失效日期、核对日期和说明。企业可新增、修改、停用；修改按版本并发控制，并记录修改人、原因及前后值。升级不自动覆盖企业已保存的规则。

已核对的主要依据：

- [《医疗器械经营监督管理办法》](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_51afc62ef3c84455b28b113a628f9e35.html)，2022-05-01 施行：第四条的一类无需经营许可和备案、二类备案、三类许可；第二十五条免备案例外；第二十七条注册人/备案人自行销售相关条件。营业执照在模板中作为企业身份资料，不能替代经营许可。
- [《药品经营和使用质量监督管理办法》](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_db526cfcd7204874b8b23297fa3b02dc.html)，2024-01-01 施行：第三条的经营许可、持有人自行销售和零售要求等。持有人自行销售模板须核对具体产品归属与适用条件，不能用于替代任意代理销售资格。
- [2017 年《医疗器械分类目录》公告转载](https://scjgj.wuhan.gov.cn/zwgk_65/zcfgyjd/zcfg_6163/201709/t20170925_140809.shtml)：分类目录与风险管理类别分开表达；本次支持记录目录版本及证件范围，不宣称已导入所有调整公告和完整产品分类库。

这九项是首批通用规则，不表示特殊药品、全部经营主体和地方要求已覆盖；没有自动订阅法规更新。真实试点仍需按实际许可证与内部要求补齐，但日常调整不需要修改程序。

同时解除已发现的内置业务必填及职员状态字典的只读限制。商品字段条件在商品字段配置中修改。历史身份、已引用编码和已过账事实保持稳定，不能把业务规则可配置理解为可改写历史交易事实。

## 4. 已审核资料的修改便利性

1. 编辑商品属性、证件续期、范围或单位资料，保存为该主体的待审核变更；无需先停用整份主体，也不需要分别审核每张证件。
2. 原有效资料继续服务交易。列表显示“变更待审”，待审核筛选也能找到这些已审核主体。
3. 支持多次续录同一批变更、查看原有效值与待审核值，并可填写原因撤回整批变更。撤回保留审计记录。
4. 审核人从主体入口一次通过全部资料。新建或修订证件随主体审核成为已核验；申请停用的证件在主体审核后停用。
5. 审核在同一事务内完成；字段错误、证件版本冲突或权限失败时整体回滚。当前参与修改者不能审核自己这批修改。
6. 日常联系信息、经营备注等原有无需审核的内容仍按其维护方式直接保存；后续统一审核不会用旧草稿覆盖这期间的新日常信息。

商品关联证件保存明确版本。修改本商品发起的证件时可直接续录并提交主体审核；同证被其他商品引用时，不会静默改写其他商品的已审核证件快照。

主体审核与业务单据审核各有用途。本次取消的是主体内部的重复审核层，不变更采购、销售和库存业务原有独立复核职责。

## 5. 后端与兼容处理

新增 `catalog_change_bundle`、`party_scope_profile`、`qualification_rules` 三张强制租户隔离表；追加商品器械分类编码/目录版本，旧单位有效期允许空值。迁移不删除原资料，不将现有测试单位伪造为具备新的真实资质。

新增规则读取/保存、主体变更读取/撤回、单位范围读取/保存接口。原证件单独 VERIFY 接口明确返回随主体审核提示；停用成为主体待审核变更。

实际采购、批发及销售公共库存预占路径采用范围判断，并重验审批后变化的证件。仅提醒模式的检查结果写入业务快照，单据详情显示提醒。不通过旧的单位统一截止时间误伤已经采用范围管理的单位。

旧集中式往来范围保留历史兼容；新编辑入口集中在往来单位。既有未迁移档案继续适用原路径，不自动启用演示企业的新本企业范围配置。
