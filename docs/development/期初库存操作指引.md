# 期初库存操作指引（含批量导入）

入口：库存 → 期初库存。用于新启用实体仓库接入已有合格实物及账面成本。请先完成商品资料审核，并在“资料 → 仓库与库位”建好仓库和库位。

## 开账步骤

1. 仓储员、业务操作员或管理员选择“新建期初库存”，选定仓库，填写原实盘清单 / 旧系统清单凭据号。
2. 按商品、批号和库位逐行填写生产日期、有效期、基本单位数量及该行账面成本总额（元，最多两位小数）。同商品同批号不同库位可拆行；同库位重复行应先合并。
3. 核对该仓完整清单后保存。此时没有可售库存和成本流水；输入错误可取消后重新建单。
4. 由另一位有审核权限的成员核查实物和账面成本，填写核验凭据及审核说明，审核通过或拒绝。制单人不能审核本单。
5. 审核通过后，由非制单人执行“启用期初库存”，再次确认完整性。系统以启用当天登记期初数量及成本，同时生成不可重复的过账、审计和事件记录。
6. 到“库存查询”和“库存台账”核对；台账动作显示“期初启用”。随后可按正常流程采购、批发销售、零售、调拨或盘点。

仓储保存后，质管可从“企业工作台 → 进销存业务待办 → 期初待审核”按单号、清单凭据或仓库名称进入原单。审核通过后切换到“期初待启用”，完成后该单移出待办；返回待办保留原筛选。可见待办不代表有审核或启用权限。完整岗位步骤见[空白企业开账验收清单](空白企业开账验收清单.md)。

## 批量导入清单

入口：新建期初库存 → 选择启用仓库 → 从原库存清单导入。

1. 下载“期初库存导入模板”，使用 Excel 或其他表格软件填写。保存为 **CSV UTF-8**；目前不直接读取 `.xlsx` / `.xls` 或 GBK 文件。
2. SKU编码、库位编码和批号按文本保存，避免前导零丢失或科学计数法转换。日期使用 `YYYY-MM-DD`；保留全部七个列名，可调整列顺序，不增加其他列。
3. 选择文件，查看商品名称、单位、批号日期、数量及成本预览。错误按文件行号列出，可切换“只看需要更正的行”。未知 SKU、其他仓库库位、已过期 / 未来生产日期、数量精度、重复行、同批号日期冲突和金额格式均会提示。
4. 修正原文件后重新选择。存在错误时不能填入，也不能误点保存旧清单；关闭导入预览后可恢复原有手工录入。
5. 校验通过后，核对行数和成本合计，点击“核对后填入清单（替换现有行）”。该操作替换下方尚未保存的全部商品行，可以继续修改；若原清单凭据为空，则预填文件名。
6. 填写开账说明并保存，再按前述流程独立审核、启用。导入预览及填入清单均不会增加库存，实际保存和启用仍由服务端重新验证业务资格、权限和库存状态。

| 列名 | 填写内容 |
| --- | --- |
| SKU编码 | 已审核且可用于期初的 SKU 编码，按原文本匹配 |
| 库位编码 | 当前选中仓库内的库位编码 |
| 批号 | 原实物批号，最多100字，不含换行 |
| 生产日期 | 有效日期，不能晚于今天 |
| 有效期至 | 不早于今天和生产日期，最晚9999-12-30 |
| 期初数量 | 正数，基本单位；最多6位小数且必须符合该SKU数量精度 |
| 期初成本金额 | 该行全部数量的账面成本总额，非负、最多2位小数，不是单价 |

单次文件最多 **200 行、512 KB**。超限明确拒绝，不截断、不跳过错误行；同仓应一次准备完整清单，不能通过分批启用绕过限制。文件只在浏览器内读取与预览，原始 CSV 不作为附件保存；正式保存后的清单数据沿用现有审计。预览期间切换仓库、主体或离开页面会清除导入预览，需在正确范围重新选择文件。

## 数量与成本示例

较早到期批次 4 个、成本 40 元；较晚到期批次 6 个、成本 90 元。启用合计 10 个、成本 130 元。正常零售 3 个，优先分配较早到期批次，扣减成本 30 元，剩余两个批次分别 1 和 6 个，成本合计 100 元。

期初登记不生成采购单、供应商应付或现金收付。旧应收应付、现金余额应通过后续相应开账功能接入，不能填入期初存货成本冒充往来结算。

## 当前范围

- 单仓一次完整启用，当前最多 200 行，支持按基本单位手工登记或 CSV UTF-8 批量填入；Excel 原格式、超大清单、历史日期回填和开账冲销尚未实现。
- 仅支持已审核、资质和效期有效的普通批次合格商品；隔离品、特殊管理商品和序列号商品不在本版期初范围。
- 已有到货或任何库存记录的仓库不开放期初，即使当前数量已清零；同仓已启用记录不能再次开账。
- 保存后仓库仍可能发生其他业务，因此审核及启用时都会重新检查。若已登记到货，应取消期初单并核查实际启用安排。
- 已启用清单和商品行不直接修改；盘盈盘亏按实际盘点业务处理，不能用重复期初替代更正。
- 普通业务人员可制单 / 取消，管理员和质量审核员有审核 / 启用权限；只读角色可查清单。
