# 记录查询三视图实施与验收

日期：2026-10-21。版本：0.36.0。业务库 b0054 / 控制库 c0017，102 张强制 RLS 表，无数据库迁移。

## 本次交付范围

采购、销售新增独立记录查询页面；采购工作区的采购／收货／验收／入库记录按钮进入查询页面，销售工作区增加销售记录查询入口。质量记录也使用同一查询组件，默认采购验收类型。业务办理页保留原来的制单、审核、收货、验收和过账任务。

本轮覆盖采购订单、采购收货、采购验收、采购入库、销售订单、销售出库六种单据事实。退货、调拨、盘点、期初、零售与财务已有页面未在本轮重构，不将其计为本轮交付。

## 三个页签和联动方式

- **单据汇总**：每张单据一行，显示发生时间、往来单位、仓库、状态、明细条数、商品种数、金额；验收另有包含合格／拒收品的条数。同一行兼有合格与拒收时会分别计入，两者不作为互斥分类相加。
- **单据明细**：每张单据的实际商品行一行。点击汇总单据号，以真实单据 ID 下钻，并切换明细页签。上方显示单据限定，可解除。单据类型、页签、筛选和单据限定写入 URL，支持复制地址、刷新及页面级浏览器前后导航；同页筛选替换当前地址，使用页签或解除限定返回更大查询范围。
- **图形化报表**：条形图、折线图、环形图、精确数据表。按日、月、往来单位、仓库、商品、状态／结果分组；统计含税、未税、税额、单据数、条数、指定单位的数量。统计服务端全部筛选结果，不以当前50行页面代替整体。

三个页签共用已应用的查询条件。修改条件后，在执行查询前显示“尚未应用”提示并禁用导出。明细商品／批号筛选同时作用于汇总和图表，汇总金额为**匹配明细金额**，不是包含未匹配行的整张原单总额。关联查询明确清除原筛选并定位所选单据，避免原条件把关联记录隐藏。

关联记录为只读抽屉，按来源订单显示相关订单、收货、验收、入出库记录；点击进入对应明细查询。每组先显示50张，超过时提供该来源订单的全部对应明细入口。不在报表正文放办理、保存、审核或过账按钮。

## 数据粒度与金额

| 查询类型 | 单据身份／行来源 | 数量与金额 |
| --- | --- | --- |
| 采购订单 | purchase_order / purchase_order_line | 当前订单内容版本的订购数量及金额 |
| 采购收货 | receipt / receipt_line | 本次实收数量；按订单金额比例折算的参考金额 |
| 采购验收 | inspection / inspection_line | 本次合格与拒收结论；参考金额，非入库应付 |
| 采购入库 | receipt_posting / posting_line | 仅已过账；实际入库数量、含税／未税／税额 |
| 销售订单 | sales_order / sales_order_line | 当前订单内容版本的订购数量及金额 |
| 销售出库 | shipment / posting_line | 仅已过账；实际出库数量与过账金额 |

收货明细不混入累计待验、已验或入库过程行；验收明细不混入收货和入库过程行。入出库采用已保存的 posting_line 金额，保持分批过账的累计舍入结果。验收与入库原库无独立业务单号，使用完整 UUID 构成稳定 YS／RK 查询编号，并明确其性质；不会伪装为法定凭证编号或写回原业务事实。

商品描述采用原单 document_snapshot，往来单位和仓库采用对应订单内容版本审核证据；未审核订单明确使用草稿资料。旧数据缺失历史时显示“历史未留存”，不静默替换成今天的主档。数量按基本单位分别合计，不将箱、个等相加；数量图表必须选单位。

分类图超过19个分组时，将剩余原始明细归为“其他”重新聚合，单据数仍使用去重计数。商品分组中同一单据可属于多个商品，不能把各商品单据数当成总体去重单据数。时间图最多366个分组，超出时明确要求改为按月或缩小范围，不悄悄截断。图表提供原始精确数值表，图形尺寸只用于视觉比较。

## 字段配置、导出与权限

汇总／明细各自配置显隐、顺序、宽度；单据号保留并固定左侧。配置按企业、账号、经营主体、单据类型和视图隔离，保存于当前浏览器，不声称跨设备同步。业务字段模板保持原用途。

CSV 按当前可见字段及顺序导出全部筛选结果，每次最多10000行，超过时拒绝并要求缩小范围；不静默截取当前页。沿用精度保留、公式前缀中和及 UTF-8 BOM 规则。

新增三个只读接口：`GET /api/v1/document-reports/{kind}`、`GET /api/v1/document-reports/{kind}/export`、`GET /api/v1/document-reports/{kind}/{id}/related`，核心 API 路径总数195。沿用 purchase.read / sales.read、经营主体授权和租户 RLS。只有 quality.read 的成员仍可查验收，但不返回金额、税率、金额字段配置或金额图表，也不能通过导出字段绕过限制；关联范围仅验收。

页面加载使用请求代次保护；切换企业／主体不展示旧数据。查询失败清除旧结果、禁用导出并提供重新查询。导出完成前重新切换上下文会放弃过时下载。列表和汇总在只读可重复读事务内取得同一批次的数据；后续刷新或导出独立取得当时数据，并显示查询时间。
