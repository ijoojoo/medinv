# 往来单位多证照与授权实施与验收

对应任务：N04。日期：2026-10-20。应用版本：0.26.0；业务迁移：b0045；控制迁移：c0017。

## 范围与资料归属

本增量在“往来单位 → 资料详情 → 质量管控”增加“往来单位证照与授权”。一个供销档案可以保存多份证照和授权书，每份独立维护、修订、核验及停用。

机构身份继续复用 `catalog_organization`。证照归属于当前经营主体的 `party`，同一机构在不同经营主体下的证照、核验和授权记录相互独立，不自动复制或覆盖。一个主体内的供应商及客户双重身份继续共用原供销档案。

旧 `license_no` 和资质起止日期原样保留，展示为类型待核对的原有单证字段。没有将旧字段自动拆成新证照，也没有自动核验、删除或替换旧准入记录。

## 可维护内容

| 内容 | 行为 |
| --- | --- |
| 证照类型与编号 | 营业执照、药品经营/生产许可、器械经营/生产许可或备案、医疗机构执业许可、授权书、其他证照。类型是资料分类，不是系统对经营资格的认定 |
| 证照主体、签发单位、签发日期 | 按原件记录；核验前须补齐主体、签发单位及原件凭据编号 |
| 适用业务 | “作为供应商供货”“作为客户购货”；按当前供销身份限制选项，双重身份可选一项或两项 |
| 原件经营范围 | 保留原文，不从自由文本推断经营准入或扩大商品类别 |
| 有效期 | 固定起止日期、原件载明长期、原件未载明、待核实；后三者不填写推测的起止日期 |
| 授权联系人 | 在授权书中维护姓名、联系电话、授权事项及该授权书有效期。可新增多份授权书，保留各自历史 |
| 原件凭据、备注、操作说明 | 当前使用纸质档案号或内部文档编号；实际附件上传另属N05 |

每个供销档案最多100份记录，包含停用记录。同一档案内同类型、同编号不能重复建档，编号忽略大小写及首尾空格；续期或更正通过修订原记录办理。其他类型若需要细分，可在备注写明原件名称。

日常联系人、电话、简称与收发货地址继续通过“经营信息”维护。授权联系人反映授权原件，不覆盖日常联系人。日常经营修改不改变证照版本、核验状态及单位审核状态。

## 核验、历史与操作保护

新增及修订后为“待核验”。修订已核验资料会清除当前核验信息并保留前后值、操作人、时间、理由及原核验历史。

建档人和本轮修订人员不能核验通过。核验通过需要独立人员具备 `catalog.review` 权限，并补齐核验凭据和说明；授权书还须具备联系人、电话和授权事项。待核实的有效期不能核验通过。

“已核验”表示记录内容经核对；固定有效期另显示“尚未生效”“在记录有效期内”或“已到期”，按数据库的北京时间日期判定，截止日当天仍在记录期间。历史过期原件可以留档核验，不因此变为当前有效。

停用保留记录及历史。重新启用须先修订为待核验，再由独立人员核验。没有删除入口。

列表、详情、新增、修订及核验均检查租户、主体和权限。修改使用版本冲突检查；命令支持原请求重试。并发创建同一编号只允许一份记录，提交前授权失效时证照、幂等结果和审计一并回滚。

页面切换资料页签保留正在编辑的表单；返回列表或关闭工作区时提示保存、放弃或取消关闭。未保存表单属于当前浏览器会话，不作为服务端持久草稿。

## 与购销业务的边界

本增量是多证照及授权档案，不改变已有采购、销售的单位资质审核入口。新增、核验或停用一份补充证照不会自动审核或停用整个往来单位。已有交易仍使用原有单位审核、有效期及交易检查。

结构化经营范围、具体证照对采购/销售的准入规则、附件原件与历史绑定分别由N05、N06接入。N04没有实现证照到期自动提醒、平台验证、证照OCR、附件上传或第三方同步。

## 开发接口与数据结构

新增表 `med.party_certificate`，使用租户复合主键/外键、强制租户RLS、编号唯一约束、日期及核验状态约束。运行角色仅获查询、新增和更新权限。

| 方法 | 路径 | 权限与用途 |
| --- | --- | --- |
| GET | `/api/v1/catalog/parties/{id}/certificates` | `catalog.read`，证照列表、适用业务及旧字段投影 |
| POST | 同上 | `catalog.write`，新增待核验记录 |
| GET | `/api/v1/catalog/parties/{id}/certificates/{certificate_id}` | `catalog.read`，详情及每页50条历史 |
| POST | 上一路径加 `/revise` | `catalog.write`，按 `expected_version` 修订 |
| POST | 上一路径加 `/review` | `catalog.review`，核验或停用 |

写入沿用同源、CSRF、上下文版本、幂等键和提交授权保护。审计关联原供销档案，使用现有证照审计动作，并以 `certificate_domain=party` 区分证照字段展示。

OpenAPI快照更新为165条路径。交付配置更新为0.26.0、b0045/c0017、93张强制RLS业务表；基础租户安全测试从交付配置读取表数，并明确检查新增证照表。
