# 多商品分批履约与缺货补货验收（0.24）

2026-10-17，本机“分批履约企业-e94e3f94”完成从新商品首次销售、按单采购、分次到货验收、三批发货、拒收补货到往来核销的连续验证。使用管理员、采购、仓储、质管、销售、财务六个真实岗位，资料、批次和款项均为虚拟测试数据。

## 本轮补通的主线

原先商品必须在经营主体已有库存控制记录才能进入批发商品选项和销售单，导致已审核新商品尚无采购记录时，不能先接销售订单，也无法生成关联补货采购。

现允许当前有效、已审核、非特殊管理且未冻结的商品先建立批发需求，再独立审核、按单补货。商品尚无库存记录时，可售数量显示0；建单和审核不会建立库存、成本、应收或应付，审核仍按原规则占用信用额度。原本存在的冻结状态继续拦截。未审核、资质过期、客户经营范围不符、序列号管理或不符合批次管理的商品仍被拒绝。

实际发货分配仍重新检查库存控制和合格可用量，没有库存时不能分配。零售仍要求库存准入和一次足量预占，未放开缺货零售。销售修改、重新审核沿用同一准入规则。

## 业务人员操作顺序

1. 采购员建立虚拟OTC药品（基本单位盒）和普通器械（基本单位支），质管独立审核商品及同时经营药械的往来单位；管理员建立资金账户和客户授信。
2. 销售员在“批发销售”选择两种尚无采购、库存记录的新商品，开药品10盒、每盒16.95元和器械8支、每支33.90元的销售单，质管独立审核。销售员可查看缺货，不能代采购员生成采购单。
3. 采购员从工作台原销售单进入“缺货与补货”，选择供应商，按基本单位进价11.30元/盒、22.60元/支生成10盒和8支的关联采购；质管独立审核。采购税率13%，未税单位成本分别10元、20元。
4. 仓储首次到货4盒药品、3支器械；质管先验收药品3盒合格、1盒保留待验，器械2支合格、1支拒收。合格未入库前可售仍为0，拒收退出补货抵扣。合格入库后销售先发2盒和2支，仓储拣货、质管独立复核出库。
5. 原销售单只建议再补器械1支。采购员建立第二张关联采购，药品数量为0，不提交无需求商品。重新提交超出建议的采购被拒绝，已有待审核采购也参与抵扣。
6. 质管完成首批剩余1盒药品的验收、入库；仓储登记第一张采购的剩余6盒药品和5支器械，到齐后仍须验收、入库。销售第二次发5盒药品、3支器械。
7. 第二张补货采购到货1支器械，验收合格入库后，回原销售单第三次发3盒药品、3支器械，原销售单变为“已发齐”。
8. 仓储将首次拒收的1支器械实际交还供应商并登记；该交还只结清保管数量，不产生采购入库或应付。财务登记收款440.70元、付款293.80元，将3笔应收和4笔应付分别核销。
