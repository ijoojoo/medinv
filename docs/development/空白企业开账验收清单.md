适用日期：2026-10-17；业务版本0.24，业务库b0026、控制库c0016。供实施人员和企业各岗位在独立试用企业执行。验收示例使用虚拟普通器械；实际开账须换成企业自己的合格实物、资料、成本和交接凭据。

## 一、进入空白企业

- [ ] 实施人员按[企业开通与开账](企业开通与开账.md)准备原开通清单并执行开通。账号须预先建立并完成身份映射；开通命令不创建或重置密码。失败后使用原request_id和原清单重试。
- [ ] 管理员、采购员、仓储员、质管、销售员、收银员和财务分别登录并切换到新企业，核对顶部企业名称和可选经营主体。小团队可按现有规则兼岗，但制单与独立审核必须由不同人完成。
- [ ] 确认新企业商品、往来单位、库存流水为空；仅有约定主体、首仓和库位。未加入企业的账号不能切入或读取。
- [ ] 管理员在“资料 → 仓库与库位”核对实体仓与库位。确定各仓是否存在历史实物；有历史实物的仓必须在首次到货或库存业务前完成整仓期初。
- [ ] 管理员在“财务 → 往来结算 → 资金账户”建立可用现金账户；批发赊销前在客户信用额度入口设置经批准的额度及期限。财务、销售或收银岗位不会因为能读资料而获得这些管理权限。

## 二、建档与质管独立审核

- [ ] 采购员在“资料 → 商品档案”登记商品和SKU：核对编码、基本单位、数量精度、生产厂家、规格及资质有效期。
- [ ] 采购员在“资料 → 往来单位”登记供应商、客户或兼营单位；核对所属主体、经营范围和有效期。
- [ ] 质管按实际依据分别审核商品和往来单位，记录核验凭据。未审核、已停用、过期或不在范围内的资料不能作为合格交易资料使用。
- [ ] 仓储确认期初CSV中的SKU编码与库位编码已经建立，商品已审核；当前期初仅接受普通、非序列号管理的合格批次商品。零售范围为已审核普通器械及OTC药品。

## 三、有历史实物的仓：期初导入与交接

1. 仓储进入“库存 → 期初库存 → 新建期初库存”，选择尚未使用的实体仓，填写清单凭据并下载模板。
2. 每行按SKU、库位、批号填写生产日期、有效期、基本单位数量和**整行账面成本金额**。数量不是箱数，成本不是单价；包装数量需先换算基本单位。文件使用UTF-8 CSV，最多200行、512KiB；具体格式见[期初库存操作指引](期初库存操作指引.md)。
3. 上传后逐行核对预览与总成本，修正所有错误，再点“核对后填入清单（替换现有行）”。保存时记录期初单号；此时尚未增加可售库存。
4. 质管在“企业工作台 → 进销存业务待办”选择**期初待审核**，按期初单号、清单凭据或仓库名称查询，点“查看原单”，独立核对批号、数量、效期、成本依据及核验凭据。仓储制单人不能审核或启用自己的单。
5. 审核后返回业务待办，原筛选保留；切换到**期初待启用**继续原单并确认启用。审核通过仍未增加库存，正式启用后才生成库存和成本流水。
6. 仓储核对“库存查询”的各批次数量；财务核对“库存台账”的期初成本。期初不产生供应商应付。启用后该单不再显示开账待办。

- [ ] 实物与CSV总数量一致，逐批号和库位对应。
- [ ] CSV总成本与原账面核对数一致。
- [ ] 已启用仓不再重复导入。待审或已审清单发现错误时先取消，修正后重新制单；已启用单不能直接取消重做。
- [ ] 没有把同一批历史实物又作为普通采购收货重复入库。

仓库已经到货或有库存业务时不能再补期初。需要超过200行、导入历史应收应付或启用后逆向更正时，当前版本不具备相应能力，应记录为实施缺口，不通过拆分同仓清单规避一次启用规则。

## 四、无历史库存的仓：首次采购

没有历史实物的仓无需创建零数量期初单，直接按采购流程开始。

1. 采购员建立采购订单，指定供应商、收货仓、SKU、数量、含税单价及税率。
2. 质管独立审核；仓储按真实到货登记库位、批号、日期和数量。
3. 质管独立验收，再确认合格部分入库。保存订单、审核或登记到货都不等于合格库存已入账。
4. 仓储核对实际增加库存；财务核对库存成本和原采购应付。采购含税金额与不含税库存成本可能不同，不能用含税总额替代成本。

- [ ] 采购单、到货单、验收记录和入库凭据相互对应。
- [ ] 入库数量、批号、库位和成本正确。
- [ ] 同一入库确认重试不增加第二笔库存或应付。

## 五、首批零售与批发

**零售：**收银员在“销售 → 零售收银”选择出货仓和商品，核对数量、价格后建单预占；核对现金实收、找零并登记收款；最后按分配批号及数量核对实物，完成交付。已付款未交付可从“零售已收款待出库”继续，不能重复收款。

**批发：**销售员选择客户和出货仓制单，质管审核；销售员按可售量分配本次发货，仓储核对批号和数量拣货，质管独立复核后出库。分配可以跨多个批次，各行需分别核对，不能把显示行的先后顺序当成批次分配依据。

- [ ] 零售先使用近效期合格库存，实收和找零正确，付款与交付均已完成。
- [ ] 批发的全部分配行均完成拣货与复核；缺货只按实际可售量处理。
- [ ] 出库后各批次减少数量与实物一致，预占按已交付数量释放，成本按实际出库批次结转。
- [ ] 批发产生对应客户应收，零售现金销售不额外生成批发应收。

## 六、首笔结算与验收口径

财务先核对客户应收、供应商应付及实际收付凭据，再分别登记收款和付款，并将原款项核销到对应业务单。登记款项本身不会自动结清单据。系统只记录已实际发生的款项，不执行银行或支付机构转账。

下面是本轮固定虚拟验收路线，两个期初批次属于同一SKU：近效期4件/成本40元，后效期6件/成本90元。另一空仓采购2件，含税单价13元、税率13%；零售3件单价20元，批发3件单价20元。

| 验收节点 | 期初仓实存 | 采购仓实存 | 总库存成本（元） | 应收未结（元） | 应付未结（元） |
| --- | ---: | ---: | ---: | ---: | ---: |
| 双批次期初启用 | 10 | 0 | 130.00 | 0 | 0 |
| 空仓采购2件入库 | 10 | 2 | 153.01 | 0 | 26.00 |
| 零售出近效期3件 | 7 | 2 | 123.01 | 0 | 26.00 |
| 批发出近效期余下1件及后效期2件 | 4 | 2 | 83.01 | 60.00 | 26.00 |
| 财务登记并核销收款60元、付款26元 | 4 | 2 | 83.01 | 0 | 0 |
| 原企业开通清单重试 | 4 | 2 | 83.01 | 0 | 0 |

最终应有6条库存流水和6条成本流水：期初两行、采购一行、零售一行、批发两行。近效期批次为0件/0元，后效期批次为4件/60元，采购批次为2件/23.01元，预占为0。虚拟账户记录净增加94元（零售60 + 批发60 − 采购26），这不是银行余额或总账余额。

- [ ] 库存实存、库存流水累计、成本池数量三者一致；成本流水累计与成本池金额一致。
- [ ] 应收应付已按实际款项核销，本路线均为0。
- [ ] 本企业业务待办已结清；其他试用路线若仍有待办，应说明原单及未完原因。待办暂不包含普通款项核销，不能仅凭待办为空判断财务已结清。
- [ ] 管理员确认原清单重试没有新增企业、重置岗位或覆盖营业数据。
