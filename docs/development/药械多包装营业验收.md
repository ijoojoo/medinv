# 药械多商品、多包装营业验收（0.24）

本轮聚焦按箱、包采购和批零拆零销售。2026-10-17在本机“药械包装营业企业-ec52ed30”完成七岗位验证，所有资料与款项均为虚拟测试数据。当前仍为开发试用版。

## 本次修复

采购、批发新单录入多个不同商品时，删除较前的商品行，会触发后续行重新绑定商品，清空原先选择的包装，但保留数量和单价。例如原本的“2箱”可能变成“2盒”提交。

现为每个商品行保留独立身份，删除其他行后继续保留该行包装、数量和单价；主动更换本行商品仍清空本行旧包装，防止跨商品使用包装。页面内部身份不提交给接口。采购、销售改单页和零售购物车原本已有稳定行标识，保持现有行为。

修复前真实浏览器已复现包装丢失；修复后同一路线完整通过。当前没有根据已过账数据自动修改单据，历史记录仍保持原样。

## 实际办理顺序

1. 采购建单：先添加一条准备删除的商品，再添加药品2箱、器械3包。删除第一行，核对剩余包装、数量、单价不变。保存结果为药品24盒/271.20元、器械15支/169.50元。
2. 将药品“箱”新建为24盒并独立审核启用，旧12盒包装退役。原采购单继续独立审核、收货、验收和入库，仍只入库24盒药品和15支器械，成本分别240元和150元；应付合计440.70元。
3. 批发建单：药品2中包，每中包36元；器械0.5箱，每箱120元。重复删除前行的检查；主动切换第一行商品仅清空该行包装，第二行保持不变。正确保存后分配、拣货、独立复核及出库，扣减6盒药品、5支器械，应收132元。
4. 零售建单：药品3盒，每盒15元；器械1包，每包65元。移除药品后器械仍为原包装，再加入药品。合计110元，现金实收120元、找零10元。
5. 在已收款待交付期间，将器械“包”新建为10支并独立审核。原零售单仍按旧包装交付5支器械和3盒药品；新比例不改变原单预占、数量和成本。
6. 财务登记客户收款132元、供应商付款440.70元，分别核销原应收应付。库存、成本及全部业务待办再次核对。

收货、验收、拣货、复核与零售交付数量都按基本单位填写。以上比例、商品类别和可拆零条件仅服务于本次验收。
