# 同仓移库操作指引（0.24）

入口：库存 → 同仓移库。用于同一实体仓库内的货架整理、库位调整；每单移动一个来源库位批次，可以只移动其中一部分。

## 操作流程

1. 在“资料 → 仓库与库位”准备好同仓目标库位。
2. 点击“新建移库单”，按商品名称、SKU 编码或批号查找库存，选择来源批次。
3. 选择同仓目标库位，填写基本单位数量、核对实物批号、填写原因，保存申请。当前只支持自有、合格、资质与效期有效的普通批次。
4. 另一位有调拨审核权限的人员打开单据，选择“独立审核移库”，通过或拒绝。制单人不能审核自己的单据。
5. 审核通过后，由有调拨发出权限的人员核对实物移至目标库位，点击“确认库位移动”，再次核对批号、数量、目标位置并确认实物交接。制单人可以执行已由他人审核的移库单。
6. 状态变为“已移动”。在库存查询中核对两个库位，在库存台账中查看“同仓移库”一减一增的两条流水。

申请和审核不占用库存；确认时会重新检查未占用数量。不要将尚未移动的申请视为已在目标库位，也不要将操作失败视为实物可以无需核对。

## 数量与成本示例

来源 A-01 有 10 个，申请移 4 个到 A-02。申请和审核阶段仍为 A-01 10 个、A-02 0 个；确认成功后为 6 个、4 个。仓库总量仍为 10，批号、效期和质量状态保持不变，共享批次成本数量及金额不变，不生成应收应付或收付款。

目标库位已有同商品、同批号、同质量的库存时合并数量；否则创建对应库存余额。移库后的两个库位可继续正常销售分配。若需移回，按目标库存另开一张移库单，不删除原移动记录。

## 异常与权限

- 销售已预占、其他业务已占用或受阻的数量不能移动。审核后可用量变化导致不足时，原单仍为待移动，两边库存都不变；核对后可以取消并重新申请合适数量。
- 商品或批次冻结、资质失效、过期会拦截确认；盘点冻结也会阻止移动。处理原因后可重试，不能用移库绕开限制。
- 未审核或已审核但未移动的单可以取消；独立审核拒绝也进入已取消。已移动记录不可修改、取消或删除。
- 重复提交同一申请或重复确认已成功的单据，不会重复移动库存。结果不确定时刷新原单核对，不要立即另开同样的申请。
- 只读人员可查列表和详情；本模块复用已有调拨读取、申请、审核、发出权限。所有接口仍按租户和经营主体隔离。
- 采购退货继续按原入库库位校验库存；已移走的货物如需按原单退回，可先核对实物并移回原库位，再办理采购退货。

## 当前范围与升级

支持同主体、同一实体仓、不同库位之间的自有合格普通批次；一次确认移动本单全部数量。跨仓使用“仓库调拨”；隔离 / 不合格品使用质量处置。多商品移库、序列号器械、特殊管制品、跨货主、库位容量和已过账冲销后续实现。

升级前停止写入及后台任务、备份数据库，业务迁移至 b0025（新增两张移库表），控制库保持 c0014，部署一致的 0.24 API / 管理端后恢复。复用 `MED_TRANSFER_COMMANDS_ENABLED`，不新增权限迁移；本机已启用。当前为开发验证版本。
