# 原单退货操作指引（0.23）

本轮把采购、批发销售的原单和既有退货流程接起来。可以在同一业务页面查看某次入库 / 出库的退货进度、申请本次退货、继续未办完的申请，办完返回原订单。

## 采购退货

1. 进入“采购 → 采购入库”，打开采购单。
2. 在相应到货单中找到已入库的验收批次，点击“本次入库退货与进度”。同一到货单可分次验收，各次入库分别办理退货；请核对入库序号、验收备注、商品批号、数量和金额。
3. 页面显示本次入库原金额、已完成退货金额，以及逐行原数量 / 已退数量 / 剩余可退。点击“申请本次退货”，勾选商品并填写基本单位数量和原因。
4. 由独立人员复核，再确认退货出库。必须有足量原库位可用库存；过账沿既有规则扣减库存 / 成本并冲减应付。
5. 从退货详情返回列表后，仍留在当前原单退货进度；点击“返回原单”回到采购详情。多次退货记录均可重新打开。

尚未入库的采购拒收品，继续使用到货单的“拒收退回”流程，不通过已入库退货处理。

## 批发销售退货

1. 进入“销售 → 批发销售”，打开销售单。
2. 在相应已出库发货子单点击“本次出库退货与进度”。退货关联该次出库，其他发货子单各自独立。
3. 申请本次退货后登记隔离收货，独立人员验收并确认退货入库。过账后恢复库存和原成本并冲减应收。
4. 返回进度页核对已退金额、剩余可退和历史记录；返回原销售单后，可继续处理其他子单。退货不会重新打开已履约数量或已关闭的订单余量。

## 待处理、历史记录和零售

- 每次原过账只能有一份待处理退货。原单进度页显示该申请及状态，使用“继续办理退货”进入；在完成或取消之前不能新开。
- 待处理 / 隔离待验 / 已复核 / 拒收待交还不扣减剩余可退，只有已完成退货计入已退。拒收品须先按原流程交还实物。数量上限与状态由服务端再次校验。
- 退货记录每页 50 条，包含取消记录；累计已退金额和当前待办不随翻页改变。已全部退回后无法再申请。
- “售后 → 退货与退款”来源列表增加“查看进度”，可进入同一原单视图。只读人员可查看进度和详情，不能创建退货。
- 零售原单“办理原单退货”继续适用；已有待处理申请时打开该申请，全部退完后显示进度，不创建空申请。
- 退货金额不等于实际退款。原核销撤销、实际退款登记及更正继续在退货详情按权限办理，不自动发生资金收付。

## 已验证业务示例

采购入库 10 件，含税单价 13 元，应付 130 元；销售出库 3 件，含税单价 20 元，应收 60 元。销售分 1 件、2 件退回，已退累计 60 元；采购再分 4 件、6 件退回，已退累计 130 元。最终库存 0，应收、应付均为 0，原销售已履约数量仍为 3。操作中验证了待处理申请恢复、独立复核、原单往返和只读访问。
