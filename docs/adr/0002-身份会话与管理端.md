# ADR 0002：身份会话、企业授权与管理端

日期：2026-10-09。状态：已实现并在本机验证的 0.2 增量。

## 选择与职责

Keycloak 26.8.0 提供统一身份；Python 控制 API 负责业务企业身份和会话，核心 API 只读验证会话。浏览器经同源 Vite 代理访问两项服务，Vue 3 + Element Plus 呈现工作台、成员及库存页面。

身份映射严格使用 `(issuer, subject)`；邮箱和用户提交的 tenant_id 不构成企业授权。账号必须已在控制库登记并具有有效企业成员身份。当前企业开通仅有本机开发初始化脚本，正式企业注册/成员邀请下一步实现。

控制库新增 tenant、principal、entity、login_attempt、不可变 audit_event，扩展 membership 与 web_session。业务库保持 27 张强制 RLS 表。Keycloak 使用独立 med_identity 数据库与角色；control_auth 不属于数据库 owner，无 BYPASSRLS。为锁定企业行授予 `UPDATE(id)`，其他 tenant 列没有写授权。

## 登录与会话

采用机密客户端授权码 + PKCE S256，精确回调地址，state 与浏览器 HttpOnly Cookie 绑定且只能消费一次。nonce、RS256 签名、issuer、audience、azp、时效通过校验后才签发随机会话 Cookie。身份令牌加密保存，浏览器只取得业务上下文及内存 CSRF 值。

刷新令牌带有新的 ID Token 时仍需校验签名、iss/sub/aud/azp/auth_time。刷新响应允许缺少 nonce；若携带必须与初次登录一致；初次登录缺失 nonce 一律拒绝。依据 [OpenID Connect Core 12.2](https://openid.net/specs/openid-connect-core-1_0.html#RefreshTokenResponse)，已用真实 Keycloak 连续两次刷新测试和签名单元测试验证。

生产环境配置强制 HTTPS；本机 development/test 只允许回环 HTTP。Cookie HttpOnly、SameSite=Lax，HTTPS 下 Secure。控制服务不记录访问 URL，避免授权码进入默认访问日志；错误仅记录错误类别。生产代理也必须配置敏感查询参数脱敏。

会话绝对到期 8 小时；访问令牌到期后核心接口拒绝访问，前端可通过 refresh 续期。退出先撤销本地会话并清空密文，再尽力撤销 IdP refresh token；IdP 暂时不可用不恢复已退出会话。登录使用 prompt=login，本轮未实现完整 IdP 全设备退出或 back-channel logout。

## 并发刷新与企业切换

刷新流程为：控制库短事务获取 20 秒租约 → 提交 → 外部刷新 HTTP → 以租约标识、上下文代次、成员权限版本和未撤销状态为条件回写。并发实例看到有效租约返回可重试忙状态。租约超时表示旧 token 可能已被外部消费，撤销会话并要求重新登录，不拿旧 token 重试。失败或过期结果不能复活已退出或被撤权的会话。

企业切换与成员修改按企业行排序加锁，并重新验证操作人状态。切换沿用浏览器 Cookie，但递增 context_generation 并轮换 CSRF；旧标签页的业务/成员请求返回 CONTEXT_STALE。前端切换时清空缓存和对话框，并丢弃旧请求结果。

控制库撤权会使后续鉴权立即失败。已经完成鉴权并进入业务库事务的请求仍可能完成；当前没有宣称跨两个数据库的撤权与业务提交线性一致。开放关键写单据前需落实技术方案中的业务提交栅栏与并发验收。

## 成员管理

内置 OWNER/ADMIN/OPERATOR/VIEWER 权限集合由服务端决定，前端不能提交任意 permission 字符串。修改需要 expected_version，防止覆盖另一管理员的更新。修改自己、非 OWNER 修改管理角色、跨企业主体、超出管理范围等请求被拒绝。更新成员版本、撤销其当前企业会话和写入审计处于同一控制库事务。

本轮支持已有成员角色、经营主体和启停设置，不支持邀请、注册、组织树、自定义角色和权限模板。成员、商品选项和库存均有数量上限；超限明确报错，后续开发分页/搜索。

## 验证与后续

69 项后端测试覆盖旧库存正确性及身份安全边界；4 项浏览器测试连接真实 Keycloak 和 PostgreSQL，验证页面及令牌轮换。已检查桌面工作台、成员表、库存查询和手机登录布局。前端按需注册组件，主 JS 约 405 KB（gzip 140 KB）。

生产仍需 TLS 网关、机密托管与轮换运维、账号登录限流、审计检索、过期会话清理、正式企业开通、IdP 撤销事件接入、容量及恢复演练。上述是本轮增量的后续工程边界，不作为已完成验收项。
