# 技术文档包使用说明

本包对应已确认的药械批发与零售多租户 SaaS 规划，技术基线为 Vue 3、TypeScript、Java 25、Spring Boot 4.1、PostgreSQL 18，采用模块化单体、显式 SQL、数据库事务和事件幂等。

## 使用顺序

1. 技术负责人评审主文档第01至08章，确认身份服务、租户事务和库存闸门；质量及财务核定规则、结算时点和成本口径。
2. 建仓锁定受支持补丁与镜像digest，创建环境、CI和Flyway。将核心SQL用于独立空库评审，不直接导入生产。
3. 根据接口登记表安排模块。导入OpenAPI到兼容3.1的文档或Mock工具，客户端生成器需支持JSON Schema 2020-12相关关键字。
4. 完成租户隔离、预占并发、幂等过账、已收款恢复和处方用量原型，使用真实PostgreSQL运行测试矩阵。
5. 所属模块开发前补齐完整迁移、DTO、事件载荷Schema和权限回归。主文档、字典、SQL和契约变更一起评审。

## 实现边界

本包是研发技术基线，不是已经开发部署的进销存系统。SQL覆盖库存一致性核心24表，尚不含完整采购、处方、财务、身份及SaaS控制面迁移；这些对象在逻辑字典中定义。OpenAPI细化关键联调命令，其余接口已登记，需在对应模块迭代继续展开。

SQL没有库存业务存储过程，不会自动完成验收、资格、并发累计量或成本校验；应用服务必须执行主文档的事务算法。结构静态检查不能替代PostgreSQL实际执行、RLS角色测试或业务压测。

事件信封对inventory.posted给出具体载荷；其他event_type在模块交付时新增各自Schema。第三方真实API、签名和限流由取得的正式授权文档补齐，本包没有虚构平台endpoint或生产凭证。所有容量和时间数值均为设计与验收目标。
