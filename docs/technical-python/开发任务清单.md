本清单承接原规划B01至B51及主文档22章。语言切换不缩减首期业务，不以Python替换为由重新承诺工期。原28至32周为资源与试点假设下的估算；下表首六周用于验证技术路线，其后按业务模块实施。

## 每个工作包的必备交付

需求及边界、数据库迁移与字典、OpenAPI与事件Schema、权限与数据范围、状态机、正常和异常流程、事务与锁顺序、幂等业务键、审计、UI与设备行为、测试证据、观测指标、升级兼容和故障恢复必须同时交付。

任务不能因“接口返回200”或“页面可操作”自动完成。库存正确性以真实数据库的并发和重算证据确认，第三方接通以业务回执和对账确认，性能以冻结数据集的测量确认。

当前交付为设计文档，以上任务均属于接下来的研发工作，未标记任何应用功能已完成。
