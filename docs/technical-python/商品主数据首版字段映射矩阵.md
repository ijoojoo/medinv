## 角色、别名与引用规则

- regulatory_subject 保存组织 ID 与实际角色；根据监管子类型 / 器械类别显示持有人、注册人或备案人；不会回退为生产企业或服务机构。
- manufacturer 独立支持生产企业、受托生产企业；同一组织可有不同合法角色。
- base_unit 在门诊服务中显示计费单位；商品编码、身份不随标签改变。
- device_class、dosage_form、device_model 不能互换含义；这类字段禁止随意改别名。
- product_certificates 保存明确证件版本和业务适用选择；原件未载有效期的备案证件允许 NOT_STATED。
- external_codes 使用原有代码体系与命名空间，条码、UDI-DI、医保及平台代码不合并成一个裸字符串；UDI-PI 与单件追溯发生记录仍属于批次 / 业务事实。
- 其他名称各有含义：name 是规范名称，generic_name 是药品通用名，trade_name 是商品名，brand 是品牌，short_name 是内部简称，search_alias 是检索助记码。

## 类型、字典与边界

- 文本按字段数据库容量与配置长度双重限制；不接受“— / 未知 / 不适用”等伪值。金额最多 6 位小数；温湿度最多 4 位小数且受数据库容量限制；整数字段为正整数。
- 监管枚举、角色、证件类型由代码白名单控制。单位、剂型、经营范围等沿用现有商品字典；严格字典禁止无效新值，历史原值可以保留。
- required_when 为受控单条件等值规则；格式支持不含空白、ASCII 编码、数字串，不接受任意脚本或 SQL。
- 储存温度上下限、湿度范围、科室与机构归属、引用存在性 / 状态、读写权限、配置版本和记录版本在后端独立校验。
- 槽位高度 94px，标签、控件、提示区固定；集合通过弹窗维护，不在网格中撑高。
- 自定义字段只能追加稳定 custom_ 键、类型、商品作用域和独立槽位；停用保留值，不能删除或换义。

### 官方依据与适用边界

- 中药饮片基原、辅料、特殊煎煮等记载参考[国家药监局中药饮片标签规定（政府转载）](https://mdx.gov.cn/info/10173/341055.htm)及[福建省药监局标签管理指导原则](https://yjj.scjgj.fujian.gov.cn/yp/flfg/202508/t20250811_6990043.htm)。标准允许范围与实际批次资料必须分别记录；标签过渡安排不转换成系统对所有历史商品的统一强制补填。
- 特医食品配方与指导提示参考[特殊医学用途配方食品注册管理办法](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_9b1a9daffc084d819bb4d7a31d909452.html)，并结合已核对标签、注册资料录入。字段本身不提供临床营养指导或个体食用量计算。
- 婴幼儿配方食品参考[2025 年修订的产品配方注册管理办法](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2025/art_d1f3f84582f24b2497e58e12c8e27843.html)。本轮仅补原文资料；液态配方乳等监管子类及其注册关系尚需后续单独建模，不能认为现有乳粉子类已覆盖全部修订范围。
- 门诊项目字段参考[国家医保局医疗服务价格项目立项指南解读](https://www.nhsa.gov.cn/art/2025/9/29/art_202_18081.html)。此处保存项目资料，不执行地区收费标准、加收扩展规则或医保结算。
